# 动态落水投放独立重建版 v1

源码与结果均以 dynamic-drop-rebuild-v1 独立登记。我方参考了外部团队的 V1/V2 说明，两份 Word 的模型、数据和成绩均属于对方。本实现中的 coverage100 是新写的、使用区域观测年龄和已测湿区的参考规划器。参考报告中的 334/480 属于外部团队。这里的每次成功表示在个体期限内完成模拟投放。

## 复跑
从 uav-workbench 的 PowerShell 执行，沿用项目 NumPy、SciPy、CUDA PyTorch 和原生水场生成器。
```powershell
# 使用本仓库 requirements.txt 创建独立环境
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -m dynamic_drop_rebuild.analysis.checks
python -m dynamic_drop_rebuild.audit
python -m dynamic_drop_rebuild.learning
python -m dynamic_drop_rebuild.study
python -m dynamic_drop_rebuild.analysis.branches
python -m dynamic_drop_rebuild.analysis.report
```
训练与评测输出在 generated/dynamic-drop-rebuild-v1。每场结果原子写入并可跳过已完成场次；有意修改源码或参数时应使用新的结果目录。独立评测由开发门槛和 seal.json 保护。analysis 子包提供检查、诊断、汇总；不参与候选选取。

## 重建时明确采用的约定

- 地图为原生 100×100、每格 10 米浅水场。动态环境使用原生 5 秒帧，时间线性、空间双线性插值，每秒按局部 u,v 显式推进被动漂流。物理仿真可访问真值，策略仅能读四机在五秒决策点圆形足迹内的格心与人员。没有风、主动游动、定位噪声或漏检机制。
- 落水候选均匀抽取格心和 [0,1080] 整秒（为每人留满 240 秒）。水深至少 0.01 米的格子允许落水；水深至少 2 米或流速至少 1 米/秒时必然接受，其余湿格每次曝光以 **0.10** 接受，直到 40 人。这个随机接受率与出生时段均为重建约定，没有真实落水率含义。
- 每布局在全域均匀生成 12 个半径 4 米的挂靠区，与水动力网格解耦。漂移线段取最早挂靠交点；已到浅滩的人员按每秒规则复漂，当秒只改状态、下一秒才恢复漂移。已挂靠者保持静止；出域即失败。人轨迹与释放随机数在飞行前产生，按父图、布局、事件类别分流；每人每秒按固定表取值。完成和截止时的潜在轨迹不会影响其他人。
- 每个整秒先推移人员、再核对刚结束的一秒是否全程在 10 米范围：在本离散服务积分中用双方该秒两端位置判定，必须由同机连续 10 秒。恰在原截止秒完成有效；超出期限失败。机体每秒最多 10 米，每 5 秒决策，联合运动保留连续轨迹 5 米间距冲突停机及二次复查。报告 conflict_stops 为受阻机步。
- 已发现人员的分配采用全队最近可用机贪心，并优先延续圈内服务。瞄准上次实测坐标；最多追踪距实测 10 秒的记录。在该坐标被再次覆盖但未见人时使记录失效。个体真期限不进入调度。搜索机去 100 米方格中心，依次选区、惩罚同一步已选邻区；coverage100 重访年龄尺度为 240 秒，湿度权重为 3，距离衰减尺度 180 米。详见 planner.plan。模型只修改该巡查评分。
- 预测器读每区的已测比例、当前覆盖、观测年龄、实际可见湿格比例、h/u/v、公开发现事件、时钟、四邻摘要与四条区域边界的法向信息。普通插值为两区间距内的距离时间加权，最近 12 步权重 exp(-年龄步数/4)。G 组额外用区域四邻精度 I+L 对 h、u、v 分量分别估计；观测精度取衰减后的采样支持量/20。输出后验均值与共享标准差、边界法向速度及深度加权代理。后验只用于特征，不生成落水人员。该重建采用区域尺度 GMRF，区别于固定人员研究线的目标中心模型。
- 决策前的标签只含此刻未发现、已落水、在域内且未到期的人数，不含未来事件。L 组读取展开的 12 帧，与 T 组使用相同历史。各输入帧的统计摘要来自当时合法历史。线性与 GRU 均用 Poisson 目标、Adam 0.001，32 个 epoch，训练从每条轨迹每 30 秒抽一个标签、保留此前全部 12 帧。线性以种子 11 拟合一个版本；GRU 各有 11/29/47 三个优化种子。
- 21001–21012 拟合、21013–21016 校准，每图四布局；31001–31006 为一次性开发检查；181001–181050 为通过门槛后生成的新父图，每图两布局。layout 从零编号。样本间只按父图作独立推断。独立确认使用校准预选模型，其余消融结果作机制说明。部署组和固定 alpha=.5 的匹配对照分别报告。
- 同场分支在开发集 60 米主档，固定种子 11，每个布局与学习组按前中后各抽最多一个有分歧的巡查时点。只改变该时点选择、随后恢复 B0；逐人明细含额外与失去的首次发现及按期投放。离线指标在整条 B0 轨迹上计算。
