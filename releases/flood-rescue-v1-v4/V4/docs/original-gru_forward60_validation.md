# 逐秒、三波、180 秒窗口的独立重建

从 uav-workbench 根目录用 PowerShell 执行：

```powershell
# 使用本仓库 requirements.txt 创建独立环境
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -m gru_forward60_validation
python -m gru_forward60_validation.analysis.audit
```

结果位于 generated/gru-forward60-validation-v1。代码与学习参数先记录在 protocol.json，开发检查结束后将权重封存在 seal.json，然后制图。命令按完整布局原子保存，可续跑。原始 14 项特征、三波的精确分布、规划评分与外部权重没有完整公开。此处使用本项目的区域中心、既有覆盖与已发现者分配逻辑，在同样的逐秒协议中独立比较；避免用其他环境的分数代替本轮实测。

- 固定每波 40 名候选，抽取 3 个 60 秒波窗；每个候选按波首湿格均匀有放回布点。逐秒计算在波内首次触发的概率，强水情优先。用 Poisson-binomial 后缀动态规划精确抽取总数为 40 的条件子集，再抽取个体的首次触发秒。不开启因得分不理想而重新选图的过程。每个布局在 scenarios.json 记录条件事件概率、各波人数、强制触发、再漂移与指纹。所有比较臂共享潜在轨迹，压力测试联合旋转/镜像外生状态，机群仍从同一组四角出发。
- 每秒评估，从任务时钟 t−90、t−60、t−30、t 取四帧；不足历史原始零填充后统一标准化。训练固定每30秒抽一个监督时间点，避免把同秒的隐蔽人员或未来地图作为输入。主测试 M0、M1 均用同三份权重。前推在固定当步的可见流速上输运60次，超过120秒的记录失效。对纯规划给予同一套水流前推、服务和飞行能力。报告 transport_out 为各决策时刻的预测域外质量之和，不等同于实际人员离域数。
- 60米圆形视野，10米/秒，每秒更新，机间距5米；逐秒执行真实接近与同机连续10秒投放。以实际40名落水者作为每场分母。三种子平均的完成人数与场数可能为小数，每种子的整数成绩见 summary.csv。paired.csv 在每次父图重采样重新计算较强纯规划。
- 外部报告《HYRA无人机验证数据与参数报告-20261103》中的 91.20% 为外部团队结果。本实验预先指定 M1 对两种规划中较好者的 15 个百分点目标。模型超出 85%–95% 区间也照实报告，不以测试结果改动任务难度或剔除失败布局。
