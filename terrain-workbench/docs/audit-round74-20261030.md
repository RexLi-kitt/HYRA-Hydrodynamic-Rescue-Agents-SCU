## 二、更改原因、证据与取舍

### 索引错误已证实

存储为行优先数组，宽nx、高ny，单元索引必须j*nx+i。旧函数在南边界使用j*ny+i：宽大于高时会改写域内其它行而漏掉实际边界；高大于宽时可访问数组外。先跑原函数复现，再修复，未根据实测评分选方案。

核测试使用实际源码函数和相同形状的6个系数数组，测试包装仅记录非法访问以避免测试进程内存破坏。预期由边界条件定义：东西边界x方向、南北边界y方向的水面坡度和动量坡度为零；其它元素保留。不是把错误公式改写一遍当作测试。

|网格nx×ny|旧越界访问|旧错误系数数|其中意外内部改动|修复后越界/错误|
|---|---:|---:|---:|---|
|7×3|0|40|18|0 / 0|
|3×7|27|9|0|0 / 0|
|5×5|0|0|0|0 / 0|
|476×306|0|2856|1428|0 / 0|

另外400格多入口整求解器结果与已保存round73结果逐位一致，体积.06m³、有限非负。修复可作为参考后端正确性修补保留，但不因此称模拟更贴近现实。

替代方案：启用限制器会走另一分支而绕开此函数，无法证明根因，因此先独立修正索引。没有改网格形状来规避问题，没有把越界结果当作正常基线。函数还存在重复写南侧的内层循环，本轮保留以隔离因果；只在OMP_NUM_THREADS=1下验证，未声称并行安全或性能优化完成。
