## 二、更改原因及证据

全域累计峰值不能替代测点指定观测时窗峰值；将干点或越界点当0也会改变评分。本轮先建立独立统计接口，使调用者必须给出时窗并看到缺测情况，不自动移动观测时间、不插值补造峰值。

确定性合成记录示例：t=0,1,2,3,4秒，速度99,3,None,2,50m/s，其中t=2为dry，统计[1,3]。返回峰值3m/s、时刻1秒、样本3、湿样本2、缺测1；不会返回窗外99m/s，也不把dry当真实零流速。示例数值仅测试逻辑，不是物理洪水或实测。原始记录和返回值在window-example.json。

选择只统计现有记录而不时间插值，是因为插值不能恢复未采到的峰值；未来连续观测比较须先明确采样频率和缺测规则。返回缺测标记不代表可以删点后宣称误差达标，评分调用者仍需制定完整覆盖策略。严格时间顺序针对单个模拟测点记录；不适合直接读含重复时间的实验原始观测，后者不得擅自去重。

## 三、目标可行性及验收

验收依据为确定性集合与最大值定义：排除窗外大峰、保留首次平峰、区分缺测和真实0、拒绝混合测点及非法时间。新增3项与上一轮5项共8项专项通过（0.030秒），0跳过。时间/存储成本O(N)，尚未开展大规模性能测试。

已实现Python采样记录的显式时窗统计；尚未接入界面、自动逐步测点记录器或Merewether评分。不同运行恰好同坐标/同方法的记录仍需调用者按运行ID隔离，本接口不自动识别运行来源。端点有样本也不代表时窗内采样足够密，最大间隔仅提示采样覆盖而非连续时间保证。
