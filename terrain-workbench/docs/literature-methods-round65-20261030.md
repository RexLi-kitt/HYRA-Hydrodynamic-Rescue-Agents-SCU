## 二、更改原因与文献依据

1. [Kesserwani等，2023，Shallow-flow velocity predictions using discontinuous Galerkin solutions](https://eprints.whiterose.ac.uk/197348/1/2210.16972.pdf)直接比较Merewether物理实验。原输入为最初干床、38m南侧口恒定来流、北侧自由出流、其余封闭；n=.042来自作者既有率定。论文比较0–800秒最大流速，不能换成750–800秒均值。选择DG2的理由是同实验及公开输入可复现，而非预先保证本机40点达标。该论文的流速改善结论有流态/分辨率限制，不能推导无限加密会更好。
2. [Shaw等，2021，LISFLOOD-FP8.0](https://gmd.copernicus.org/articles/14/3577/2021/index.html)提供成熟DG2/FV1 CPU/GPU实现。该求解器能原生读取这套实验的三个地形系数文件，可避免自行重写非平床三角网格适配和边界。GPU速度必须本机端到端计时，不能搬用文献倍数。
3. [Kesserwani等，2025，Discontinuous Galerkin simulator of shallow vortical flow with turbulence](https://eprints.whiterose.ac.uk/id/eprint/225534/1/Manuscript_unmarked_Accepted_Preprint.pdf)提出深度平均二维RANS-k-epsilon，并在五组实验中研究复合涡。它提供比直接全域三维NS更窄的物理扩展路线，不能解释为本Merewether案例已经验证。附录A还需要入流湍流强度及黏性比；本案例缺这些测量/依据，所以仅列后续候选，不能套默认值反复拟合40点。
4. [官方DG2预处理说明](https://www.seamlesswave.com/Merewether2-4.html)要求平均值及两个坡度系数；[测点说明](https://www.seamlesswave.com/Merewether1-5.html)提示预处理后坐标约定。需对照源代码明确原物理坐标到计算坐标的固定转换，不能通过移点试分选择偏移。当前只保存原坐标，尚未实施转换或新参考长跑。

替代取舍：ANUGA已有引擎可用，但本机 `shallow_water/boundaries.py::Inflow_boundary` 明确标为work in progress、相关测试关闭，且局部坡度为0、用1m回退水深。故暂不把该类直接当作本实验流量边界。ANUGA本身仍保留作为验证后端；不能据一个边界类否定整个求解器。先构建作者官方DG2参考更便于闭合输入，之后再考虑匹配ANUGA边界。
