# 洪水模拟修改框架与第一轮边界试验

## 目标与顺序
保留二维浅水方程；通过可回退、单因素实验排查误差，不直接升级三维NS。

1. **观测口径**：核实40点最大流速的采样时窗、测速高度和时间平均方式，确认与深度平均模拟速度可比；维持原型尺度，不二次缩放。冻结现有40点评分脚本。
2. **几何表示**：以报告的地面/障碍分层版本为基线，分开改变地面聚合和障碍表示；局部加密桥墩和窄通道。至少三档网格，记录障碍面积、通水宽度、40点误差及计算时间，不仅看单项RMSE。
3. **边界条件**：只替换北侧出口，再单独改入口动量，最后才做组合。固定地形、初始条件、流量、糙率和采样；用800秒完整运行验证，避免只用某时刻通量差解释全域误差。
4. **独立求解器**：同一地形/边界/采样口径下与成熟二维求解器比较，分清实现差异和共同模型局限。
5. **局部三维验证门槛**：只有在以上因素受控、加密后误差仍稳定存在且有明显垂向流动物理证据时，才选择局部三维模型；不将40点误差直接归因于浅水假设。

每项验收记录：全部40点最大速度RMSE/MAE/偏差、共同有效点方向误差、漏淹点数、质量守恒、网格与运行时间。不得通过删除差点改善评分；不得用同一40点调参与验收后宣称泛化。

## 已完成验证
4项新增测试通过（包含两种通量及四个流向的均匀流测试）；11项原有数值测试通过。

外部目标条件为均匀流持续穿过区域。外推模式水深及速度平均绝对误差均为0；原模式水深偏离0.08426m、速度偏离0.27277m/s。原模式体积从96降为87.91107m³，变化与边界出流守恒一致。
**解释**：这是不同边界物理设定产生不同解的验证，不证明原模式存在数值bug，也不能把这些数值当Merewether误差改善。只出不进模式用于无外部补水的场景时可能是有意设计。
