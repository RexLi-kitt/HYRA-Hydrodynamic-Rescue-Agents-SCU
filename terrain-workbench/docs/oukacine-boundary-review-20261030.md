几何横向闭合：7×.064+6×.079+2×.039=1.000米，说明.079米是柱间净间隙而非中心距；中心距.143米。纵向首排x=.17米的具体柱缘/中心定义仍须核对图，不靠算式猜位置。既有文献±5mm位置偏差仍保留。
来源表1的H=.055米是空间平均观测，Hweir=.037米是堰高；二者均不能直接充当已知局部出口水位。用目标平均水深设出口、再以平均水深证明拟合会造成证据重复。
补查论文引用的独立阻力研究：Guillén-Ludeña等，https://ascelibrary.org/doi/10.1061/%28ASCE%29HY.1943-7900.0001676 ，出版社摘要区分床摩阻和障碍形阻，可作为进一步核对方向。本次未取得并核实全文系数，不能据摘要给草床赋Manning n。作者机构条目 https://portalinvestigacion.upct.es/documentos/61860dae8a2f583ff09b3ee6 给出仓储句柄；网页工具打开 https://hdl.handle.net/10317/13335 与 https://hal.science/hal-03234688/document 均失败。记录为获取限制，不表示论文或数据不存在，也不需用户立即处理。

## 三、目标可行性与最小后续步骤
1. 先获得独立草床阻力关系和适用深度/流量范围；若只得到总阻力，不得与显式柱障碍阻力重复叠加。需核实堰的有效宽度、形状、流量关系/局部水位及参考高程；不拿堰高冒充水位。
2. 在这些输入闭合前，不启动全槽实测评分，也不任意设糙率。必要时可以预登记一个末端水位观测作为边界，但其本身必须从独立评分中标为输入，剩余内场点才是留出；当前尚无足够局部出口观测支持此路线。
3. 闭合后先跑未经拟合的实验原尺度基线；稳态停止依质量储量、流量及水位滚动变化预登记判据，随后另设统计采样段。原文40/400/3600秒不能混用；数值稳态容差及现实误差阈值尚未有完整依据，暂不填数。
4. 保留24位置已公开水深统计的真实聚合含义；不能声称恢复72个原始观测。三维ADV仍不能直接作为二维深均真值。先以水深验证，再决定速度缺测区积分假设及其不确定性。
