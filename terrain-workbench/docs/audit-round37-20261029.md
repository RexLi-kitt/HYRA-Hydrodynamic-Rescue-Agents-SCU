# 第三十七轮：连续流量来源与独立性核查
日期2026-10-29；基线7043b2c及第26—36轮本地修改。仅研究资料与审计工具更改，未改物理公式。

## 一、更改日志
新增benchmarks/round37_discharge_provenance.py::audit，读取第36轮原样记录，核验时间轴一致后比较流量与原始/平滑库容差分；新增observation-provenance.json，记录测量/推导区别、单位、相关性和适用范围。第36轮原始文件与结果不覆盖。回退为停用审计工具及新注释，生产默认不变。

## 二、更改原因与证据
找到对应原论文Chen等（2026），DOI10.1029/2025WR040786，公开全文：https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2025WR040786 。以下论文事实与本地计算分开记录：
论文表1给出CP-1入流1.21 m³/s，确认此处流量单位。2.2.1节说明压力水位仪每秒采样、标称精度±0.3 cm；库容由水位与地形关系估计，出流通过入流减库容变化率推导，并采用移动平均。2.2.3节的PTV是表面流速，不是水深平均流速。研究对象包含坝体冲蚀，不能当固定床瞬时撤坝。

本地数值检验（不依赖推测）：对1934个有效相邻区间，使用原始Qin=1.2118，比较Qout[t]与Qin-(V[t]-V[t-1])/1s。
|库容版本|1934点流量RMSE m³/s|最大绝对差m³/s|
|---|---:|---:|
|原始库容|.4608426468|5.274892086|
|三点平滑库容|0|0|
平滑库容后向差分精确重现已有Q序列。因此水位、库容和流量不是三组独立测量证据；用该水位驱动库容变化再对比推导流量，会产生循环验证风险。
原序列有262个负流量点，其中527—909秒破坝时段有8点。保留全部，不裁剪、不删除；差分会放大水位起伏，但本轮不能断言所有负值都只是噪声，也不能把它们认定为已测得真实回流。首条缺测与差分没有前值一致，仍保留null。

## 三、目标可行性
已实现：确认m³/s单位，量化数据派生依赖，避免把推导量当独立观测。检验标准是时间严格递增且一致、保留缺测、按论文守恒关系审计；结果完整保存derivation-check.json。
尚未实现：CP-1完整空间几何、冲蚀模型、测点绝对基准及总观测不确定性。传感器±.003m不是整套模拟允许误差，不能直接用作精度验收门槛。solver_ready仍false。
本轮仅标准NumPy序列差分，计算成本秒级，无水动力实验、未重复生产回归，无精度提升声明。工具能检查原始与平滑版本，不仅验证预期成功路径；没有为了匹配改动数据。
