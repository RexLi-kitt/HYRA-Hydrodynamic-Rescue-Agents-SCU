# 搜救相关定性吻合度：两组完整实验结果复核

日期2026-10-30，回应“测试几个方面数据然后告诉我吻合度”。这是对已有完整结果与原始实验观测的重新计算，不是新跑一遍长模拟，也不是现场洪水准确率。事前规则及输入哈希在qualitative_request/protocol.json；所有逐时段、逐测点及780对速度比较均在result.json。没有删掉失败和未知项。

## 可证实的结果

以下Merewether主列是已完成的0.7m基线，Okushiri为准确物理域6mm版本。不同实验不能平均成一个“现实符合度”。

涨退趋势的35个可确定时段中33个一致（94.3%），但其余34段仍未知，不能把94.3%说成整体水情准确率。两处明确反向为ch9的7–8s及ch7的21–22s。主峰观测先后ch9→ch7→ch5，而模拟ch7→ch9→ch5；主峰先后不是洪水到达先后。

粗流向规则是与观测向量夹角不超过45°，保留旧基准的.05m/s方向可判别下限。这是本次明确登记的描述性分类，不是仪器误差范围，也不是证明搜救可用的标准。38个可判方向点中34个一致（89.5%）；另有2个未知。4个不符点全部保留：15-J、19-F、20-G、20-H；19-F约90.19°，落在相反半平面的一侧，但距离90°很近，未闭合测量误差时不可夸大为确定的强回流。19-J与21-I无法按旧方向门槛判定，零速度不表示干燥。

相对急缓比较全部40点两两组合，以观测最大流速的大小次序对照模拟0–800s采样最大值。相等或无法区分的记录算未知。可判713对中412对一致（57.8%），仍有301对排序相反。780对来自同一组40点，并非780次独立实验。没有将“看起来快”直接映射到人员安全等级。

## 版本、证据和限制

两组Merewether均核对1600条完整时间序列、全部40点、最终有限非负数组；原CSV的ID、坐标、速度和Mod_Angle逐点一致。来源是Zenodo6914888缩尺物理模型速度测量并换算到原型尺度，不是现场40个流速站。Okushiri的451×3值与原观测厘米单位换算逐项一致，沿用第69轮规则，未移时或去偏。

当前工作目录与保存快照不是全部字节相同；差异包括新增HLLC可选分支、审计及哈希清单，完整diff已保存。本次统计明确属于已完成Rusanov配置，未把旧结果冒充当前所有可选路径的新跑成绩，也未为此重复800秒长跑。第76轮新LF8参考候选只完成内部60秒启动测试，以上实验吻合度不能转移给它。

空间会不会淹、道路是否阻断、起降候选是否受影响，不能由40个速度点或三条水位线推出。Carlisle真实事件尚缺同事件完整计算及起时/边界闭合，没有可报告的现场吻合率。未知不是干地，最高水位不是局部水深，主峰不是到达，且尚无人员分布证据检验实际搜索优先级。

结论：测点粗流向已有较多实验支持；相对急缓排序较弱，涨退和峰序仍有明确失败。尚不满足“全部登记定性项目一致”，也不能给可靠的总体现实吻合百分比。这次改变/补充评价没有让算法本身精度上升。
