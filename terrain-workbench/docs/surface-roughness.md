# 静态地表糙率

新洪水场景默认 roughness_mode=landcover。复用原生地表、群系、材质和植被覆盖，不重新生成地图，不引入随机逐格系数。统一糙率对照使用 roughness_mode=uniform 与原有 manning 值。

## 数据与优先级

完整地表已有 ground_block_id、biome_id、cover_flags。cover_flags 的 tree=1、other_vegetation=2、snow_layer_or_powder=4、ice=8 来自原导出器；它们不包含植被高度或密度。快速预览没有这些信息，仅使用地形类别近似；山地、丘陵等地貌名称不自动等同于裸岩，未知类别使用 manning 回退值。

自动赋值先使用地形，再使用群系代理；实际材质和覆盖优先于代理，河流、湖泊和海洋身份最后覆盖。树冠所在格使用树木覆盖阻力，不在全森林群系里额外随机造树。没有覆盖标记的旧完整图保留群系植被代理。河道分类包含岸边干格时，河槽赋值属于静态近似。

显式 layers.n 覆盖自动基础值，roughness 编辑补丁再覆盖数组。合并网格前先在原生格上赋值、应用补丁，再按面积平均 n；这只是沿用当前合并方法，不保证等效过水能力。切换格宽不会仅凭粗格类别重新查表。

## v1 初值

| 类别 | Manning n |
|---|---:|
| 天然河槽 | 0.035 |
| 湖泊、海域底床 | 0.030 |
| 裸土、黏土、砂质地表 | 0.025 |
| 砂砾 | 0.035 |
| 裸岩 | 0.030 |
| 草本地表 | 0.035 |
| 灌丛、高秆植被 | 0.060 |
| 树木覆盖 | 0.100 |
| 草本湿地 | 0.070 |
| 木本湿地 | 0.120 |
| 硬化地表 | 0.015 |
| 雪冰覆盖地表 | 0.030 |

这些是项目初始估计，不是实测或率定结果，也不是将参考表逐项直接照搬。群系不等于精确土地覆盖，湿地群系和覆盖标记不能确定植被密度。道路只在材质能识别时归类，不从地貌虚构道路。湖泊/海域数值代表底床阻力，不是水面粗糙度；没有海冰阻力模型。

方法参考：[HEC-RAS 地表分类与糙率图层](https://www.hec.usace.army.mil/confluence/rasdocs/r2dum/6.0/developing-a-terrain-model-and-geospatial-layers/creating-land-cover-mannings-n-values-and-impervious-layers)。文献初值仍需针对水深、观测和模型尺度检验。静态 n 不承担入渗，也不重复代替已明确建模的建筑、墙或堤防。

## 查看与复现

工作台场景设置可选分类或统一模式；现有糙率图层和查点使用实际 M_base.n。scenario_metadata.roughness 保存版本 hyra-static-landcover-v1、源图层、原生分类统计、回退格数、最终范围和人工编辑信息；分类统计在显式数组/补丁覆盖前计算。最终 M_base.n 在 JSON 和 NPZ 中随场景保存，历史已计算过程不重算。

网页导入/恢复没有 roughness_mode 的历史场景时选择 uniform，避免重新应用时悄悄改变旧统一糙率。新API请求缺省为 landcover；需复现旧统一配置时显式指定 uniform。已有网格对照脚本固定 uniform，原试验结果不改写。
