# 第三十轮：初始干床细高程接入局部加密
2026-10-29，基线7043b2c及第26—29轮未提交研究。目录HYRA-PR-20261029。本轮未提交推送，原研究目录不动。

## 一、更改日志
refined_solver.RefinedFloodSolver.from_solver新增关键字fine_bed/fine_dx，默认None，原默认继承父格模式不变。输入必须是与父网格同原点、同方向、同覆盖范围的2倍行列高程，格距为父格一半；只抽取加密父格对应四子格。其余父格继续原高程。数组形状/格距可验证，但无地理坐标信息，无法自动证明用户给出的真实空间对齐，调用方必须负责。
只允许未步进、全干床且无初始动量/历史水深的状态；不支持非空水工结构，不允许改变外边界父格高程，避免与仍基于父格的边界设置不一致。建筑solid和墙面继续继承，不支持细掩膜替换。父格bed更新为叶格面积投影用于显示，真实演算用leaf bed；numerical_config标明实验模式。
另修正_transport中限流系数：原where=outgoing>0可能在dt*outgoing下溢成0时除零。改为先计算requested，仅当requested>available才求比值；没有缺水时保持1，与原有限正常情形等价。本轮12组结果在警告修复前后完全一致。
新增benchmarks/round30_fine_terrain.py和tests/test_fine_terrain.py。源快照/哈希及原始结果均在outputs/round30。
回退：调用时不传fine_bed/fine_dx恢复父格继承路径。若撤销本轮实现，仅撤销refined_solver本轮差异及新增脚本/测试；不能重置其他未提交研究。没有更改默认网格或自动启用场景。

## 二、更改原因与定量对照
原加密只把父格高程复制四份，已被粗化抬高的窄通道无法恢复。这是数据表示能力的缺口，不是以测点为目标挖槽。本轮使用预先定义的合成地形验证：12×16个1m父格，1m高横断障碍，中间保留0.5m宽、2m长低槽；局部2:1加密。源项.2m³/s持续3秒，总水量.6m³；总演算6秒、n=.02、dt上限.02s。均匀0.5m细格采用等面积源分配，作为独立网格数值参照而非现实观测。另将低槽封闭，并旋转两个方向，共12组。

|开启低槽的方案|6秒下游体积(m³)|说明|
|---|---:|---|
|加密但继承粗格高程|0|低槽已丢失，完全不通|
|加密且读取细高程|0.0082023652|恢复过水|
|均匀细网格|0.0110176257|数值对照|

新方案比均匀细格的该指标仍低25.55%，未达到收敛或现实精度标准。两方向差异约2e-18m³，封闭低槽的全部方案下游体积均为0；守恒残差最大2.22e-16m³，有限非负。不能将“通了”夸大为“流量已准确”。
最初对照出现极小通量除零警告；修复后设置RuntimeWarning为异常重跑12组，无警告且结果逐项不变。新增静水检验用细高程建立等水面叶格初始条件，保持静止；这是测试初始化，不意味着API已支持湿状态替换地形。

## 三、目标可行性、验证与限制
预先验收见plan.json：守恒残差<1e-9m³、真实封闭障碍下游水量<1e-10m³、旋转差异<1e-9m³，全部满足。没有预先依据设置现实精度阈值；均匀细格差异如实保留。
4项新测试覆盖行列/子格映射、输入数组独立性、未加密格不变、无效/湿状态拒绝、静水、真实阻水和旋转；全套242项239通过3跳过，19.536秒。12组对照约6秒级，本机仅小域，不可外推真实区域时间。
已实现：实验性半格距床面输入、窄通道过水恢复、守恒稳定保护。部分实现：与均匀细格接近但仍有25.55%差异。尚未实现：细建筑掩膜、湿初始状态转换、多级加密、地图界面接入、Merewether改善或现场验证。
下一步先扩展窄槽网格/加密缓冲范围敏感性，确认混合网格过流误差；再审查Merewether中可只改床面且不改变粗建筑掩膜的区域。不能把本接口说成已能恢复所有支柱/建筑开口。保留全部观测与评分口径，不自动推送。
无后台实验。总体“与现实基本拟合”目标尚未达到。
