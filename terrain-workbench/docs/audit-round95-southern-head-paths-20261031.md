# 第95轮：南部漏片的水位—地形通路区分（2026-10-31）

本轮按用户“先这样来”的授权执行第一项区分实验，复用第91轮完整结果；没有新水动力运行，没有生产/网页默认修改，原88.56%正例覆盖与24884漏格全部保留。诊断目标是第92轮已定位的最大南部漏片2031，1457格、36425平方米；此为事后归因范围，不替换冻结的全域验收范围。

## 方法、理由与完成条件

先保存protocol.json及全部输入SHA256，再读取结果。固定漏片外扩100m的矩形（南边距模型边界20m），对所有12个六小时保存场分别用每个已湿格自身水面高程作为起点，以四邻接、沿途地形+0.1m严格低于起点水位为可达规则传播。另做异步最大水深的乐观上界诊断。全程不加模拟来水、不编辑DEM；但是静态传播本身假设无限水量、无沿程损失、无传播时间，因此不是物理洪水模型，也不是新增模拟受淹区域。

成功条件为全部1457格计数闭合、13个场由独立算法完全复核、实际来源水位与通路可追溯；否决条件为输入变化、复核失败、将潜在通路当实际淹没。计算用时数秒，不重跑旧68.25小时过程。

## 结果及解释

- 至少一个保存时刻的理想静态条件下可达680格，其余777格在这些场内无此通路。异步最大场可达779格、不可达678格；新增99格只来自异步最大条件，不能当作真实同时供水。
- 漏片内全部6个调查点保留：17、18、25具有静态可达通路；12、20、26仍不可达，其格地形分别为19.66、22.68、25.67m，均高于原记录峰水位。这不是允许削低地形的依据。
- 可达的3点在保存文件check-0005.wdb使用的最高起点为(E339937.5,N554722.5)，水深0.715770m、水面17.355769m。按这个恒定水位求最短静态通路，17/18/25分别840/810/545m；超过沿途最高地形再加原0.1m指示的余量仅0.01577/0.01577/0.05577m。它们不是实测流路，也不是水力最优路径。
- 路线上首个未达0.1m格为(E339952.5,N554772.5)，格地形17.200001m，实际水深0.037875m；前一湿格实际水面17.244035m，较起点下降约0.111734m。把起点水位不衰减地搬到全路径会夸大供水能力，不能据静态可达就认定数值漏水。
- 结论：南部漏淹不能统一解释为“地形绝对封死”；但仍不能在“地形偏高、局部供水不足、阻力/时程影响、遗漏结构过程”之间确定唯一根因。本轮没有可采用的物理修复、无拟合提升。
