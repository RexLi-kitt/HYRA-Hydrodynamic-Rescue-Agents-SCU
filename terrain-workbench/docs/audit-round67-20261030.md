# 第67轮 真实水位定性标签与空间案例资料审计

日期2026-10-30；基线7043b2c及全部现有未提交修改。阶段Q1已有证据落表/Q2现场案例筛选。没有运行新的洪水模拟，也没有获得新的模型现实一致性结论。

## 一 更改日志

新增flood-platform/benchmarks/prepare_harvey_qualitative.py的validate_archive、net_label、prepare函数：对现有Harvey记录与USGS官方响应逐条核验，再将完整窗口按固定UTC六小时分段。输入仍为USGS08075000的原769条15分钟相对水尺水位；无平滑、插值、裁点、移时或改变观测。输出标签、逐段证据行号/记录ID、段内反向变化、机器可读对照表和观测曲线。输出目录已存在则拒绝覆盖。

预登记harvey-label-protocol.json：端点差大于+.01ft为净上涨，小于-.01ft为净退水，其余表示在记录分辨率下不确定。.01ft来源于两个按.01ft记录的端点合并舍入范围，不是仪器精度或安全标准；另检验.02ft。6h是本次观测组织尺度，不是已验证搜救响应窗口。禁止将净趋势当成全段单调变化或洪水到达时间。

新文件只处理资料/标签，生产函数、物理参数和默认算法均未改。回退为停用新增后处理入口，保留原始数据及历史结果。文件哈希见manifest.json。定时仍ACTIVE每5分钟；当前无长实验。

## 二 更改原因与证据

用户要求定性搜救信息，先需要独立、可重复的真实观测标签。检查发现现有Harvey小档案可直接复用；USGS官方重新获取响应共769条，与本地各时刻、单位、站号、序列、审批/质量标记和数值全部一致。保留完整官方响应及原来源URL，读的是归档审定版，不等同2017实时接收版本。水位相对水尺基准，绝对基准未闭合，不得当作街道积水深度。

固定32段中9段净上涨、23段净退水；24段同时存在正负方向的逐记录变化，已全部保留，证明只看端点会漏掉局部波动。记录分辨率带从.01ft到.02ft时32段标签无变化；这不等于测量不确定性已验证。窗口内最高原记录45.67ft，UTC2017-08-27T17:30:00Z。没有同域HYRA模拟，所以32段对照全部“无法判断”，不是32段通过。

源数据：[USGS官方连续记录接口](https://api.waterdata.usgs.gov/ogcapi/v1/collections/continuous/items?f=json&monitoring_location_id=USGS-08075000&parameter_code=00065&datetime=2017-08-25T00%3A00%3A00Z%2F2017-09-02T00%3A00%3A00Z&limit=10000)。本地flood-data-workbench/data/harvey-2017/manifest.json保留原来源与缺口。此站预留为验证记录，不能用同一条曲线强迫边界后再称独立拟合。

### 空间资料没有冒充已具备

1. GEOID/巴基斯坦资料：仓库有10月21日对齐说明、元数据和PNG预览，但在当前开发库、旧HYRA及整合版的已记录.runtime/source-screening位置未找到原栅格；在两个项目工作根的定向文件检索也未找到关键原文件。只能说这些已检查位置缺原件，不能断言个人电脑所有位置均丢失。没有从预览图反推标签或伪造水深；现有Harvey2km地形亦为现代概览，不是已核实2017河床。
2. Carlisle：[作者官方算例](https://www.seamlesswave.com/Carlistle_flooding.html)给出5m处理DEM、三路经1D推演的来水及68h案例；公开T07目录现有par/bci/bdy/stage/readme共5项，目录没有DEM和现场观测范围。该教程展示的范围基准可以是另一软件输出，不能当现场真值。保存API清单，未启动模拟。
3. [McClean等2020论文](https://doi.org/10.1029/2020WR028241)说明Carlisle实地水位/范围观测及地形影响，并链接[作者数据包](https://doi.org/10.25405/data.ncl.12807095.v1)。已定位进一步取得资料的具体来源；数据包API和教程readme下载各一次遇到SSL EOF，错误原文保存，未循环重试或更改安全设置。尚未取得包内观测文件，不能宣称案例输入/验证已闭合。

替代取舍：先把本地真实过程变成可追溯标签；不重新模拟Merewether，也不先跑一个缺独立观测的Carlisle长任务。遥感派生空间范围、测站水位、作者推演来水、软件输出分别记录证据类别，不能相互替代。

## 三 目标可行性与下一步

已实现：真实水位769条复核；32个有依据的净趋势标签、内部波动和不确定字段；现场案例资料缺口可定位。部分实现：Q1/Q2证据准备。尚未验证：任何新增现场模拟定性一致性、全域淹没/干区、流向、相对急缓、道路和无人机任务排序。本轮没有代码物理精度提升。

下一单元优先取得一个现场案例的独立空间观测和可用水动力输入：先核验Carlisle作者包是否含现场范围/洪痕、可用DEM和许可；只有软件结果或缺原测量则不作为现实验收。GEOID/Pakistan可作为缺原栅格恢复候选，按已有哈希少量恢复，不能重复下载全数据。Harvey32段等待同域边界/历史基准闭合；不得为了生成“对照”把观测当模拟或将他处结果挪来匹配。缺口若后续仍无法补齐，报告具体需要的资料/受限用途，继续已有完整实验的独立定性核验，不无限资料搜索或盲试。

成本：仅小型API响应、769记录处理及静态图，无重型模拟/算力争抢。验证：完整769逐条核验；缺记录、错误单位、移时、改官方值4类破坏均拒绝；JSON解析/脚本语法/图像检查及双份报告一致。跳过数值回归（未改求解器）；没有新现场模型运行可评分。数据预处理成功不算水动力拟合成功。
