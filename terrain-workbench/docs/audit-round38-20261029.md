# 第三十八轮：真正混合粗细网格的二维干湿验证
日期2026-10-29；基线7043b2c及第26—37轮本地修改。保留全部未提交变更，无推送。

## 一、更改日志
新增benchmarks/round38_mixed_mesh.py::run，使用右半域2:1加密、左半域粗格，在每个叶格用实际宽度积分解析深度，误差和水体中心按叶格面积加权。生产算法及默认参数未改；回退为停用该独立脚本。两套网格父/子尺寸为.4/.2 m、.2/.1 m，CFL分别.4和.2，maxdt=.02 s。

## 二、更改原因与证据
第33—35轮只有全域加密，无法证明粗细交界可靠；直接算叶格误差算术平均又会过度加权细格区。本轮固定4×4 m抛物盆地及Thacker旋转平面水面、同初态/摩阻0，模拟一周期4.485701465466374 s，水体及岸线穿越x=0交界，每季度记录。证据为解析解，不是实测。来源及公式沿用第33轮SWASHES 4.2.2： https://www.idpoisson.fr/lucas/wp-content/uploads/sites/33/2018/12/DeLuKsDaLaVoJaCo13-IJNMF-complements.pdf 。
初始化直接给解析叶格床面/水深/动量，再start_scenario，只是验证初始化，不推广湿态细地形导入接口。床面为每格精确面积平均，水深Gauss16积分并以Gauss8作敏感性比较。没有因细格数量较多而重复计权。

空间细化后加权水深误差减少约61.27%；细网格CFL减半，实际步数1050→2099，误差变化约.0535%，仍主要受空间表示与数值处理影响。粗网格中心偏差大，不应因质量守恒就认定精度足够。
.2/.1m混合网格误差.002119894 m，高于第33轮全域.1m的.000838303 m。这一比较同时改变了左半域分辨率和交界数量，不能把全部差额归咎于交界算法缺陷；需要匹配自由度/几何和换位控制才能进一步归因。未加权均值.002577925 m与正确加权不同，说明混合网格评分口径必须明确。

## 三、目标可行性
已实现：真正粗细交界条件下一个周期干湿变化、面积权重、时间步实际变化及网格敏感性验证。
预设检查：总面积16 m²、有限非负、绝对水量残差<1e-9 m³、精确季度时刻。4运行16样本通过，最大小量守恒误差仍在浮点范围。网格改善不是场景真实精度验收，也未预设事后误差通关线。
尚未验证：多周期混合网格、交界方位/位置敏感性、真实地形数据和独立测站过程；不以本轮结果宣称阶段完成或候选默认应替换。
成本：4组小网格运行，耗时elapsed_s随结果保存；无需新观测。大网格成本和实际现场误差仍不确定。
