## 案例登记

- 案例及事件日期：〔填写〕
- 证据类别：〔现场事件／实验室观测／解析／软件对照〕；真实拟合结论只能由相应实测支持。
- 区域与对象：〔固定区域、建筑、道路、起降候选点ID〕；先选定再看模拟结果。
- 观测原始来源和文件哈希：〔填写〕；观测获取时间、时区、坐标基准：〔填写〕。
- 模拟版本、输入、初始/边界条件和时窗：〔填写〕；输入与独立验证资料分别列出。
- 有效观测范围及遮挡、云、缺测、永久水体：〔填写〕；有效非水区也需明确。
- 评价尺度与时间分段：〔街区/通道/测站；事件前、上涨、峰值附近、退水〕。缺阶段资料不能补猜；不移动原时间。
- 关键搜救对象及任务：〔搜索区、地面接近通道、起降候选点、漂浮目标；没有人员证据时不推断真实受困人数〕。
- 事前分类依据：〔图像中可辨边界、地标高程、独立水位/视频、路段阻断记录等〕；数值阈值如有，登记依据和边界不确定带。

## 如何判定

- 一致：同一对象、同一可比时段、依据同一预先登记规则，观测与模拟类别相同。只支持这一项和这一范围。
- 部分一致：大方向或主区域相同，但预先列出的局部分支/边缘不同，且尚无关键决策反转。列出差异，不能事后把坏点排除为“不重要”。
- 不一致：类别或明确先后顺序相反；真实受淹关键区被判为干地、已阻断通道被判为可用等都属于关键错误。
- 无法判断：观测、时刻、定位或分类依据不足，或对象落在预登记的不确定带。不得算作一致，也不自动算作干区。

完成某一已登记研究用途的条件：先冻结案例、区域、时间、搜救相关指标及分类规则；所有纳入验收的对象和时段均有独立观测支持，逐项结论全部为“一致”。“部分一致”“不一致”“无法判断”均不能算通过，也不能用平均一致率掩盖漏淹、反向流动或错误通道判断。不得在看过结果后删除失败项、缩小范围或放宽分类来宣称全通过。局部数值误差只有在不改变预定定性类别时才可不作主门槛。允许分别交付已验证范围与仍未验证的研究训练场景，但不得称全部目标已完成。这里的全部一致仅限已测试条件，不意味着保证任意真实洪水全部正确；观测自身的不确定性仍须明确。

## 可降低优先级与仍须保留的内容

不改变搜索区、任务顺序、起降候选或地面接近判断的局部速度数值差异、微小涡旋细节，可降低研发优先级。仍保存数值和不利结果，不删除点来增加一致率。

守恒、非负/有限、坐标方向、时间对应及重大漏淹继续检查。零速度不等于干地；求解器干湿阈值或0.01m采样门槛不等于安全阈值。洪水受影响区主要改变搜索价值、目标与地面条件，不能直接当无人机禁飞区；建筑避障、天气、通信、续航、返航和空域规则另行处理。

## 执行步骤与失败转向

1. 冻结案例、区域/阶段、分类依据和关键对象，再提取观测标签；标签保留原证据位置。
2. 先复用已有结果，按同坐标同时间提取模拟标签。缺观测就写未知，不为得到结论重跑。
3. 逐行核对，优先处理会导致关键漏搜、错判通道/起降点或涨退趋势反转的差异。
4. 差异可定位到输入/几何/边界/代码时，登记一个有依据的候选和否决条件，再做最小区分实验及完整相关时窗比较。无收益换证据方向，不盲换公式。
5. 原因不明或关键资料缺失时，列明所需资料及替代公开案例；不得以全域NS/GPU替代证据。GPU只改变成本；局部NS需目标量受三维效应影响的证据。
6. 在限定可靠与未知水情上先跑固定无人机策略，再研究集群优化；保持人员分布、感知范围/延迟、续航等条件一致，禁止用未来真值。

## 第一批数据如何使用

Merewether已有40点最大速度与模拟，可先检查显著“有流却未复现”等局部矛盾；它不能独立验证全域淹没、干地、涨退水过程、道路通行或人员排序。Okushiri连续水位可用于波动阶段与站点过程，证据是实验室缩尺，不能称城市现场洪灾。Harvey已有资料登记提及连续水位，须重新核对原文件/基准，并闭合同域模拟输入后才能实景比较。

真实事件下一步优先筛选有明确拍摄时间与范围的CEMS洪水观测图，并配套测站过程/现场道路记录；如果同一事件缺输入则先记录缺口，不能将别处实验模拟与现场图直接配对。CEMS DEL提供影像获取后的事件范围，更新产品可支持多时相核查：[官方产品说明](https://mapping.emergency.copernicus.eu/about/rapid-mapping-portfolio/)。洪痕反映最高水位，不能单独提供涨退水过程：[USGS说明](https://www.usgs.gov/water-science-school/science/high-water-marks-and-flooding)。


## 定性界面交付规则（v1.2）

- 六项主面板分别显示受淹、涨退、主流向、相对深浅急缓、地面通道与起降候选、搜索影响；每项附证据类别、案例时间和验证状态。
- 一致、不一致、部分一致、无法判断必须可区分；取得观测资料单独标“观测已备”，不使用通过的颜色或措辞。
- 保留所有对象/时间段及原证据定位，显示涨退顺序而不以数值误差排行榜替代；时间、区域ID及来源不是定量精度验收，可正常保留。
- 观察到的最大淹没范围单独展示；其它区域标未知，不能涂为安全干地。未运行同事件模型就明确写未对照。
- 原始水深/流速和守恒记录留在研究文件，界面不要求精确数值预测。不臆造定性标签，不能通过隐藏数值掩盖分类矛盾。
- 当前离线界面是round69证据快照，不自动更新，也不是现场指挥或实时模拟器。重建前审核其原始证据及问题文案。
