# 第43轮：Okushiri地形中心采样与面积平均单因素对照
2026-10-29；基线7043b2c+已保留26–42轮修改；工作表B2/C1/C2。

## 一、更改日志
benchmarks/run_okushiri_hyra.py新增sample_bed及--quadrature（1/4/8，默认1）。原来取ASC双线性场的格中心值；现在可用张量Gauss积分近似单元平均。默认1与第42轮床高逐位相同，生产求解器和物理参数不变。回退使用--quadrature 1。
本轮固定dx=.027m、CFL=.4、同一5.454×3.402m域、原入波、Manning=.0025、三测站和0–22.5秒窗，只改变床高积分。4×4点积分，不是改变原始地形数据或拟合测点。

## 二、更改原因与证据
有限体积床高代表单元时，中心取样与面积平均在弯曲/折线地形上可能不同。本轮检验这一输入离散因素能否解释第42轮残余误差，不能仅以某站RMSE降低决定换默认。
平面2x-3y+.7在远离源栅格边缘处，1/4/8阶最大误差均<6e-15m；默认床高与第42轮逐位一致。实际地形中心与4阶平均RMS差.085661毫米；4阶与8阶平均RMS差.005222毫米、最大差.190391毫米，因此4阶是近似积分，不能声称精确面积平均。

## 三、目标可行性及验收
已实现：独立地形采样选项、默认兼容性验证、完整三站过程敏感性。尚未验证：8阶完整过程、精确实验域东墙、原测量不确定性、网格收敛。
预定检查沿用第42轮：451原时间点无改变，曲线有限，末态非负，质量残差<1e-12m³；全部通过。目标为识别床高表示敏感性，不设事后实测合格门槛，不宣称普适精度提升。

## 定量对照与结论
中心→4阶面积平均，RMSE（实验尺度mm）：ch5 3.738152→3.733519；ch7 3.143818→3.156198；ch9 3.802282→3.808459。一站略好两站略差，不能作为推广依据。完整曲线变化见comparison_summary.json。
4阶模拟5590步、40.20秒，质量残差0、数值调整0、最小原始水深0，无负深或非有限状态。
ch9全局最高点时刻由16.75跳至17.20秒，而峰值仅.04394062→.04392283m（差约.01779毫米）。这提示峰顶多处接近时，argmax峰时容易跳变，不能单独用峰时宣称传播明显恶化。原峰时评分保留，后续可预先增加阈值到达/相关过程指标，但不得替换或隐藏原不利评分。
