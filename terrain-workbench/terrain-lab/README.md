# 地形实验台

“多层地图与洪水”（`maps.html`）统一固定环境编辑和整段洪水计算。高程、地物、糙率、水源、排水与水情共用网格；支持连续播放、暂停、倍速和时间轴拖动。[使用与数据字典](MULTILAYER.md)说明地图层、运行和导出。

运行 `python3 launcher.py`，或者双击 macOS 的 `启动页面.command`，在浏览器打开 <http://127.0.0.1:8766/>。

内置示例无需 Java 即可查看。生成新地图需要 Java 21，首次构建需要联网下载依赖。完整的安装、生成和矩阵导出说明见 [工作台说明](../README.md)。

生成器会先检查 Java 21 JDK，优先使用 `../freeterraforged-reproduction/.runtime/java/` 内解压的 JDK，再检查 `JAVA_HOME` 和 PATH。Java 24 等其他版本会立即给出提示。构建下载会使用已有系统 HTTP/HTTPS 代理；需要认证的代理请自行配置 Java。Gradle 下载使用官方直连地址并校验固定 SHA-256。

网页导出使用 Loom 的 CI 模式，跳过 IDE 依赖源码下载与转换；运行依赖与地形算法照常构建。Windows 使用 Java 参数文件传递完整类路径，并按系统编码写入，支持中文目录，避免启动器压缩类路径后找不到游戏文件或重复加载 Mixin。

首次下载和构建时显示阶段说明，进入地形计算后显示实际进度。首次依赖源码转换可能持续数分钟。可随时“取消生成”或“查看生成记录”；连续 10 分钟没有新日志、总计超过 30 分钟会自动停止并保留原地图。失败和取消后仍可查看本次记录。

“水系丰富”与“原始参数”按钮载入参数；调整后点击“生成地图”应用。快速预览提供高程与河网；完整地表进一步提供实际地面方块、水面与群系。“图片预览”打开当前图层的图片。

“目标地形”可选择稠密水网、高山、平原或自由调整。三个典型模式控制地貌权重、起伏及河网参数，并保留用户的种子、地图大小和生成方式。同一种子在不同模式下产生不同地图；同一种子、模式和请求坐标的搜索顺序可复现。修改地形滑块会回到自由调整；修改种子、范围或生成方式保留目标模式。

典型模式最多检查请求坐标附近九个区域，先检查高程和河网，再为通过的区域生成完整地表。成功结果记录实际坐标，完整地表还会重新检查；找不到符合标准的区域、取消或超时均保留原地图，不承诺每个种子和范围都能找到目标。自由调整不移动区域，也不设验收条件。一次任务的总时限仍为 30 分钟。

验收规则（当前一个方块单位对应一米）：水网要求陆地 ≥55%、有水河道占全图 ≥4%、河道覆盖至少 8/16 个分区且穿越地图边界至少三处、陆地 P95−P5 高差 ≤80 m；高山要求陆地 ≥70%、原生山地占陆地 ≥25%、陆地 P95−P5 高差 ≥80 m、P90 高程 ≥140 m；平原要求陆地 ≥70%、陆地 P95−P5 高差 ≤45 m、P90 坡度 ≤0.15。海洋与只有湖泊的场景不算水网。规则定义工作台的合成地形类型，不代表真实流域标定；水网检查验证覆盖和边界交点，不保证天然支流的拓扑结构。

低起伏模式使用原生 MULTI 大陆算法，并降低独立山脉层的幅度、统一基础高程；高山保留 UPLIFT 大陆算法。只使用原生成器配置，不修改保存的上游源码或生成后的高程。

每次搜索保存 `terrain-search.json`，成功后保存 `terrain-profile.json`（指标、模式版本、种子、请求与实际坐标、检查次数）；每个候选的生成记录独立保存。网页显示检查结果与实际区域坐标，多层洪水过程元数据也保留模式与验收报告。

运行数据、最新地图指针、生成世界与构建缓存均被 Git 忽略。无运行数据时默认显示 `example/raw`。

洪水过程已融入多层地图，旧 `flood.html` 地址自动进入 `maps.html`。支持降雨、指定来水、变化水源、入渗、日常基流预热和海平面双向交换，整段异步计算并连续播放。完整过程下载为ZIP，当前显示水情可导出JSON与PNG。需要上一级 `requirements.txt` 中的NumPy。

外源洪水支持自动标注河道入图处和手动选点，逐点配置上游流量过程、启停和时间窗口。与日常基流分别计量，入口编号、原始位置、计算格映射与累计入水保留在 `M_forcing`，方便后续场景抽样与训练接入。
