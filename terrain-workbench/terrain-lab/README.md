# 地形实验台

运行 `python3 launcher.py`，或者双击 macOS 的 `启动页面.command`，在浏览器打开 <http://127.0.0.1:8766/>。

内置示例无需 Java 即可查看。生成新地图需要 Java 21，首次构建需要联网下载依赖。完整的安装、生成和矩阵导出说明见 [工作台说明](../README.md)。

“水系丰富”与“原始参数”按钮载入参数；调整后点击“生成地图”应用。快速预览提供高程与河网；完整地表进一步提供实际地面方块、水面与群系。“图片预览”打开当前图层的图片。

运行数据、最新地图指针、生成世界与构建缓存均被 Git 忽略。无运行数据时默认显示 `example/raw`。
