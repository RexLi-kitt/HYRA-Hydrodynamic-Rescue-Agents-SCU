# HyRA 修正轮：五组同信息诊断报告

**修正轮B2平均完成率相对B0变化+4.4个百分点；均值最高为B1_distance。所有主要配对区间均包含零，本轮仍不足以支持稳定优劣。**

原轮服务失败后自动重启的环境缺陷已修复。旧报告排名不再作为机制证据，本轮重新训练所有组，没有使用旧模型替代新对照。

## 本轮只改了什么

1. 服务失败当步不重启，下一步可移动或选择重试，耗时与奖励规则保持原约定。

2. 五组均保留两条完整原始历史（观测、匹配先验、年龄、掩码），另设相同3个证据槽位。B0填零，本区组仅本区汇总，B1距离汇总，B2区域联系汇总，均匀组只改变时间权重。39×5×5输入，个体网络52,696参数，混合网络70,721参数，组间相同。

3. 增加已有诊断链内的两任务固定顺序评分，不新增在线中央规划、窗口分类器、统计surprise、同化或主动观测。参考新框架4.2历史与估计联合、4.4隔离目标发现两点；其余作为参考，没有照搬。

## 水情信息有没有改变选择的空间

仅在6训练/3验证事件上生成已知地图、单机、两目标子问题。候选路径和顺序由几何确定，当前已发布预测选顺序，再用真值评分。675个可评估情境中，32个的实际收益依赖访问顺序（4.7%）；15个存在预测选择相对两候选真值最佳的损失（2.2%）。按9事件等权平均可补救差距为每情境0.0222个任务。

共有9981个情境在读取真值评分前因路径/60s预测时域不满足被排除；这个比例较高，当前诊断只覆盖短路线。该参考是两候选集合内最佳，不是全局最优，不证明残差方法有效，也不替代未知目标、多机协调评价。时间点/布局不作为独立洪水样本。

这说明现有场景的可补救决策机会比较稀疏。应先检验任务情境与误差的可辨识性，而非仅增加模型板块来追求正结果。

## 证据利用与实现验收

固定B2模型与原GRU状态，仅置零额外汇总数值、保留共同原始信息与支持字段，3231个有支持且非服务中agent动作中6个改变（0.19%）。这是当前汇总值的即时动作敏感性；不能据此断言网络没有利用历史水情或判断训练不足。

28项测试通过；15个模型容量相同、损失有限；90条轨迹的167次成功服务区间有效，80次失败均未在同一步强制重启。旧PyMARL复制tensor提示仍存在，不影响验收。

## 下一步边界

已解决明确的恢复逻辑错误和原始信息压缩混杂；未证明区域组织或时间衰减有稳定任务增量。下一步可在现有ANUGA/服务配置内预先定义更充分的短路线与临界任务条件，或先检查训练能力，再用全新独立事件检验；不能筛到B2获胜才报告。没有自动增加在线模块。
