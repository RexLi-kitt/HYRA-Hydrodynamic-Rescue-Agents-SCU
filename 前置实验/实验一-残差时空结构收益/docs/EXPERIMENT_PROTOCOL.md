# 验证协议草案

> 当前实施以V2_PROTOCOL.md为准：五组均保留完整原始历史，增加本区残差对照，失败后恢复移动权。下文四组替换表征属于旧轮规格，旧轮排名已因环境缺陷更正。

当前未实施实验，以下是后续实现约束。

## 最小对照

| 标识 | 表示方式 | 主要问题 |
|---|---|---|
| B0_raw | 原始观测、匹配先验、相同长度历史及年龄/掩码 | 显式组织是否有增量 |
| B1_distance | 相同残差和历史，按距离联系及时间规则组织 | 普通距离组织是否已足够 |
| B2_structure | 经训练事件验证的区域联系及时间规则 | 区域组织是否有额外作用 |
| B2_uniform | 与 B2 相同，但有效期内采用均匀历史权重 | 时间衰减是否有独立增量 |

所有组采用相同最大有效年龄并剔除过期记录。固定历史长度 K 和权重归一化，避免单条证据的时间衰减被分母抵消。

如共同入流偏差占主导，可增加全局残差均值参考，检查是否只有共同偏差在起作用。

## 训练和评分约束

- 按完整独立洪水划分，关联版本按 event_family_id 分组。
- 联系在训练事件估计；参数和诊断读出器只用训练/验证数据确定，测试冻结。
- 固定回放各组使用完全相同的观测记录；匹配诊断读出器容量、调参预算和输入槽位。
- 先对统一样本集评分，再按本区证据新鲜/陈旧/缺失分层，同时报告有效覆盖。
- 指标候选为误差诊断 MAE、严重低估召回率及误报率；具体阈值和读出器尚未确定。
- 配对差值按独立事件汇总，不把连续时刻当作独立样本。

## 结论对应的证据

1. 人工构造数据：检查接口与机制能否按设计运行。
2. 独立水动力事件固定回放：检查结构与时间规则的信息增量。
3. 原策略内重新训练和闭环比较：检查行为及真实服务收益。

结构存在、证据及时、行为改变和收益提升分别报告；无稳定增量时保留该结果。当前框架没有预设任何性能提升。
