# 预测—观测残差时空先行信息：实验方案

日期：2026-10-15。状态：设计方案，尚未执行本方案实验；探索阶段完成后冻结正式参数，再开启新测试集。既有V2/V3结果仅用于设计依据，不作为新盲测。

## 1. 核心问题与边界

研究问题：在保留相同原始观测历史、已发布预测及训练预算后，上游残差是否包含下游未来预测失准的增量信息？这种信息能否在临界施救窗口关闭前转化为任务收益？

验证三个递进假设：

- H1信息：水动力联系区域的过去残差，能改善下游未来误差预测；不仅是下游自身趋势或全域共同偏差。
- H2时间：这种改善存在有效提前量，且依赖合理的方向和时滞；不能仅由同刻空间相关解释。
- H3任务：执行阶段利用该表征，在有调整余量的任务中提高实际完成率。

只改残差表征。复用ANUGA、现有QMIX/训练期价值梯度增强、服务失败恢复逻辑。保持预测器独立，不同化、不添加残差奖励，不新增在线GMRF、通信调度、漂移目标、安全控制器。称为“残差时空先行表征”；H1/H2未验证前不称“已发现残差传播规律”。物理上演化的是水位/流量扰动，残差是模型失配的观测线索。

## 2. 为什么不能继续只放大统一偏差

V3改变全域预测输入系数，真值不变。它检验受控输入失配响应，但没有隔离局部扰动的上下游传播。90对轨迹中53对行动变化，只有1对任务数变化；675个两顺序情境中的可补救选择错误15→16。新方案需有空间局部性、可观测时滞和可调整任务窗口，不能只继续加大误差。

## 3. 数据与物理扰动

沿用100m×100m、10×10任务网格、求解器2s输出、10s起报、60s预测时域。参考求解器与名义预测器使用同一基础地形/初始条件，但参考可含名义预测器未知的局部来水变化；名义轨迹及各次起报不得用参考状态或观测重置。

条件设计（同一家族配对）：

| 条件 | 参考环境 | 预测器 | 用途 |
|---|---|---|---|
| C0稳定误差 | 基础洪水，无局部脉冲 | 固定小幅输入偏差 | 区分趋势与新增扰动 |
| C1局部扰动 | 上游局部边界来水/水位脉冲，连续起落 | 不知道该脉冲，输入保持原规则 | 主要先行信息检验 |
| C2共同偏差 | 基础洪水 | 全域统一输入偏差改变 | 同步相关负对照，不能单独证明传播 |

探索阶段在训练专用家族校准可分辨的扰动：边界段宽度20m；水位脉冲幅度候选0.05/0.10/0.20m；起止各平滑10s，平台20/40s；开始时刻60/90s。只有一种扰动形式进入正式实验，具体幅值、位置集合和分布在校准后冻结。局部边界实现需单独验证边界分段和数值稳定性，不能直接给下游格点或残差数组加数。

记录原始stage/xmomentum/ymomentum、输入时序及名义状态。水动力联系依据名义求解器的扰动响应确定；不只按地图左右或距离定义上下游，也不直接用距离÷流速估算时滞。水位扰动的传递与单纯水体平移不同。参考扰动响应只用于离线核对，不作为执行时输入。

先检查数值收敛：探索家族上用更细网格/时间输出确认主要方向、响应时序和峰值不被离散设置主导；若量级/时滞变化明显，先修网格和采样规格，再冻结实验。所有方法使用相同求解器数据。

## 4. 家族划分与公平性

- 探索校准：12个全新家族，6训练/3验证/3内部诊断；不作正式效果结论。
- 正式验证：另生成36个家族，18训练/6验证/12封存测试。地形、摩阻、基础来水、初始状态及随机种子按预先冻结范围抽样。
- 同一基础洪水的C0/C1/C2、脉冲位置/幅值、噪声和延迟版本，全部留在同一划分，不能按版本随机切分。
- 测试家族不能参与选图、时滞、历史长度、阈值、模型或任务场景筛选。测试失败后调整方案必须另开版本，不能继续称同一测试集盲测。
- 探索阶段的内部诊断集是迭代数据，不作为正式盲测。正式信息读出与正式策略共同在解封前冻结，之后一次联合测试；不能先查看正式信息测试结果，再据此调策略并继续宣称策略盲测。
- 正式噪声标准差0/0.02m，观测延迟0/10s；观测条件在家族内配对，按家族生成独立噪声实现，方法间共用。噪声与延迟作为鲁棒性分析，不增加算法模块。

主结论以C1的无噪声、无延迟条件为预先指定主分析；C0/C2及退化观测全部报告，不筛选有利条件。36是计划家族数，不是统计功效保证；先用探索家族方差估计最小可检出的任务差值，再冻结正式样本数，禁止用测试结果追加样本直到显著。

## 5. 因果数据口径

在线有符号历史残差：

\[\nu_{i,s}=y_{i,s}-\hat d_{i,s}^{(s-20)}.\]

同位置、同有效时刻、同水深单位、固定20s提前量；观测必须已经到达。无匹配版本或未观测是缺失，用掩码表示，零占位不表示预测准确。保留符号、有效时间、到达时间、预测版本、年龄。

在决策时刻t，令f(t)为最近的已发布预测。未来误差标签：

\[e_{j,t}(\tau)=d^{ref}_{j,t+\tau}-\hat d^{f(t)}_{j,t+\tau},\quad \tau\in\{10,20,30\}\mathrm{s}.\]

这个标签由离线真值计算；预测输入只能使用t时刻可获得的数据。不能用t以后新发布的预测替换标签里的预测。候选时滞只能取已过去的0/10/20/30s，未来预测提前量τ与源观测年龄/时滞ℓ分别记录，不能混为一个参数。

历史长度候选2/4/6条、年龄上限60s。探索后选一个共同长度并冻结，正式各组完整原始历史完全相同；不能让主方法多拿观测或长历史。改变共同长度后，所有策略都重新训练。

## 6. 阶段一：验证先行信息，不训练救援策略

### 6.1 观测实验

先用预先布置的稀疏上下游监测格点（每截面3—5个，每10s采样）隔离先行关系，再用由地图几何决定、与真值无关的固定移动路线复核。格点/截面依据名义水动力联系确定，不能事后挑相关性最高的测试区域。

全场真值响应是离线解释上限，不能冒充无人机可获得的稀疏观测结果。无有效上游观测时主方法需返回无支持状态，而不是读取全场参考残差。

### 6.2 信息读出对照

使用相同低容量读出模型、训练规则和正则候选；模型复杂度与有效源数量尽量匹配。所有组先包含下游自身完整历史、当前预测、时间/位置和有效性字段。比较：

| 对照 | 额外信息 | 检验目的 |
|---|---|---|
| I0自身历史 | 无上游信息 | 下游趋势基线 |
| I1共同变化 | 因果可见的全域平均残差及趋势 | 排除共同输入偏差 |
| I2同刻空间 | 同一候选源的最近残差，无传播时滞 | 空间汇总基线 |
| I3方向＋时滞 | 名义水动力候选关系约束的过去残差 | 主假设 |
| I4破坏结构 | 相同源数量/历史长度，方向或过去时滞错配 | 机制负对照 |

I3必须在I0/I1基础上仍提供增量信息。全域平均只能由当时可见观测计算，不能使用参考全场。I4中打乱的也是过去记录，不允许借打乱引入未来数据。仅某条滞后相关显著，不作为独立机制证据。

物理候选图来自名义求解器响应，权重/时滞仅用训练拟合、验证选择；整个图在测试前冻结。预测局部趋势的读出各组相同，避免只有主方法具有去趋势能力。

### 6.3 指标及进入下一阶段条件

主指标：τ=20s的下游未来误差MAE，以事件家族等权；τ=10/30s、RMSE、误差符号作为次指标。再评价未来连续12s服务是否超过0.8m阈值的Brier分数、精确率—召回率和校准。水深阈值只是现有仿真服务约束，不当作人员死亡或无人机禁飞界限。

报警阈值只由训练/验证稳定条件的完整时间过程确定，目标误报率5%；测试报告实际误报率，不假定仍为5%。同时报告检测率、提前量分布和未检测事件。提前量要扣除观测延迟和可决策间隔；迟于服务决策的报警不算有效预警。

进入策略阶段的条件：I3在新家族上优于自身历史和共同变化基线，效果跨家族方向一致；正确方向/时滞优于破坏结构；改善在稀疏观测下仍可见。探索阶段目标MAE至少降低5%，但该5%是工程筛选目标，不是天然科学阈值。置信区间和样本量评估同时报告。若不满足，先定位采样、传播尺度、共同偏差或噪声问题，不以训练更大的策略代替信息证据。

## 7. 阶段二：验证临界施救增量价值

### 7.1 先检查可行动机会

沿用已知地图、单机两目标、几何先生成的两访问顺序离线诊断。路径/目标由几何和名义预测产生，再用真值核对可行服务及有限候选最佳收益。需要报告：真值顺序敏感比例、当前预测选择的可补救损失比例、可用于改行动的提前时间。此诊断不加入在线中央规划，也不是全局最优。

同时保留两套布局：一般布局（可达格点均匀生成）和临界布局。临界布局依据名义水深接近0.8m、路径耗时和预计服务时刻事先生成，绝不依据参考真值或主方法得分挑目标；冻结后保留所有成功/失败情境。两套结果分开报告，不能只展示临界布局。

若临界布局仍几乎没有可补救损失，先修正规定的任务时间尺度/几何设计并重新冻结，而非盲目扩大训练。改变任务规则后的实验不与旧轮混成一个排名。

### 7.2 五组策略对照

共同输入为同样的原始历史、已发布预测、局部任务观测及自身状态；残差额外表征统一槽位、掩码和支持信息；同样网络参数量、源数量上限、奖励、训练预算。

| 组别 | 额外残差表征 |
|---|---|
| P0原始历史 | 额外槽位填零，掩码明确 |
| P1本区时间 | 本区历史/趋势信息 |
| P2同刻空间 | 相同物理候选源的空间汇总，不使用传播时滞 |
| P3时空先行 | 正确方向＋训练冻结时滞的表征，主方法 |
| P4时滞消融 | 与P3相同边及容量，过去时滞错配或固定零时滞；探索后固定一种 |

阶段一先验证方向负对照；阶段二只保留一项最关键消融，避免扩展算法板块。若P4选择零时滞，必须与P2定义清楚区分，例如P2只用最近记录、P4仍保留同样多条历史但不做传播对齐；无法形成独立对照时取消重复组，改用方向错配。

P3只能使用当时已到达的观测与名义预测，不读取未来参考水情。先行特征作为策略输入，训练和执行均可用；原价值梯度增强仍仅训练启用，所有组一致。先不替换价值梯度、不加残差奖励，保证唯一变量是残差表征。若以后研究替换惊奇机制，另开正交消融实验。

### 7.3 训练与评价

继续使用4无人机、5未知目标、10%障碍、50步×6s、连续12s服务、0.8m服务阈值、每机2份资源；失败当步不重启、下一步可移动。服务只能完整成功计奖，噪声水深只作为观测，真值用于环境服务判定及离线评分。

探索训练：3种子×300回合，检查学习流程与容量公平，不做正式性能结论。正式训练：5种子×3000回合，每250回合用验证集平均完成任务数选模型，同分取早；禁止测试选模型。是否需要所有组统一扩到6000回合，仅根据训练/验证曲线在解封测试前决定。3000/6000均不是完整原论文训练规模，不能宣称原论文充分复现或必然收敛。

测试使用同一家族、扰动、噪声、目标和布局种子，方法/训练种子之间配对；每家族预先固定5布局，不能重复布局当成独立洪水。保留所有轨迹、观测版本、模型选择与失败原因。

主比较：C1一般布局下P3−P2的每回合实际完成任务数，作为时滞组织的增量；P3−P0检验整个表征增量。临界布局作为机制分析，单独报告。主要指标是任务数与完成率；次指标为失败服务次数、首次成功救援时间、机会错失、探索覆盖和决策响应延迟。没有成功救援的回合不能从首次救援时间统计中静默删除，应报告未发生比例或使用删失分析。

响应延迟区分：输入扰动发生→可见观测出现→表征改变→首次行动分歧→服务结果改变。第一次动作分歧本身不能当作救援有效响应。

## 8. 统计与失败解释

先按布局在家族/训练种子单元内平均，再以家族和训练种子交叉重采样给出95%区间；同一家族各条件始终一起重采样。报告效应大小及各家族差值，不将格点、时间点、布局和扰动版本当作独立洪水样本。明确主比较，多个次比较采用校正或标注探索性；正式样本量不足时结论是证据不足。

四种结果都允许：

1. 有未来误差信息且有任务增量：支持完整主线。
2. 有先行信息但无任务增量：检查提前量、任务余量、策略利用程度，不能说方法已提升搜救。
3. 同刻相关有用、方向/时滞无额外收益：收窄为残差空间关联，不称传播创新。
4. 排除自身趋势/共同偏差后无信息：暂不进入更复杂控制器，检查或放弃传播假设。

## 9. 执行顺序与产物

1. 校准局部扰动、检查求解器离散稳定性和上下游响应；输出事件清单及原始状态。
2. 在探索家族完成稀疏观测信息读出、负对照、任务机会诊断；冻结图、历史、时滞、事件分布和样本量。
3. 在正式训练/验证家族拟合表征及策略，测试封存；保存源代码快照、数据指纹与模型选择日志。
4. 一次解封正式测试；审计因果输入、配对布局、服务区间及失败恢复；报告全部条件。

交付：冻结协议与manifest、下游误差预测表、方向—时滞图、提前量分布、五组任务比较、配对轨迹、审计与失败解释。保持系统本地Python/CUDA/ANUGA环境；CPU生成水动力数据，GPU用于策略训练，不创建新独立环境。
