# 数值稳定性排查：固定物理输入后再比较精度

2026-10-15，运行前设计。只分析此前4个出现正例的旧训练家族，不作确认推断。

源码及边界检查发现：旧代码按边中点选择局地来水边界；请求中心25米时，网格10实际激励[10,30]米，网格20/40实际激励[15,35]米；另一侧同样相差5米。因此此前网格比较同时改变了物理边界位置。

本轮固定物理扰动区间为[10,30]/[60,80]米，对应所有网格都能精确表示的同一条边界。这与旧网格10的实际输入一致；保留旧网格20的输入作为单独几何对照，不将其当成同输入网格收敛序列。真值和名义探针均使用相同固定区间。

固定4家族009/012/017/020、全部32布局、两个边界区间、180/210秒锚点、0/6/12秒初始决策偏移及E0无脉冲/E1脉冲配对。180秒是先行的时间对照；同锚点E0才是直接事件对照。不得因新结果删掉负例或改服务阈值。

每条物理场同时读取最近质心和质心Delaunay三角剖分线性插值。后者在固定物理点读取，以非负重心权重计算，不称为ANUGA原生高阶重构，也不预设更正确。保留权重及原始场，可独立复算。

比较网格10/20/40的2秒输出；网格40另运行1秒输出，再从同一1秒运行抽取偶数秒。这样分别识别：空间网格、点位读取、输出间隔改变导致的积分变化、以及仅丢弃奇数秒样本的变化。ANUGA会将内部步长裁切到输出时刻，因此独立2秒与1秒运行之差不能直接称为纯记录误差。

独立名义基础场在各网格和时间间隔下生成；180/190/210/220秒重新起报60秒预测，只允许从同配置名义状态重启。分别报告冻结旧名义任务/动作下的标签敏感性，以及数值配置匹配的名义预测/动作；后者若改变任务筛选，覆盖与总体单列，不直接当成方法收益。

对所有预设候选服务区间保存跨配置的水深最大值范围。范围跨0.8米时标为“测试配置间不一致”，不是概率置信区间；保留完整分母。对冻结动作，要求同一替代顺序在每个数值配置中都增加服务，且各配置都存在相关源的因果可见配对响应，才记为“测试集合内一致的机会”。这是保守诊断，不保证对未测网格或真实环境成立。

运行前工程检查值：20→40线性读取的目标深度最大差≤5毫米、名义时滞差≤2秒、共同服务区间标签零翻转；40网格独立2秒与1秒运行的共同区间最大值差≤1毫米。逐项报告，不拼成质量分数，不在看到结果后放宽。

新结果只决定数值契约是否足以支持下一轮实验。若未通过，明确剩余误差与不一致范围；不直接训练P4或开启新的确认家族。原始旧运行不改写。
