# 后续实施顺序

当前开始按交接版实施。P0先核对，再并行可独立推进P1A原底座与P1B洪水，P2共用动态任务，P3回放，P4四组重新训练，P5完整留出与边界评价。离线正结果不是闭环接入前提。

| 顺序 | 后续工作 | 主要文件 | 验收结果 |
|---|---|---|---|
| 1 | 确定数据格式、预测口径、区域映射和事件划分 | docs/DATA_CONTRACT.md、data.py | 可检查的数据契约和事件清单 |
| 2 | 接入 ANUGA 参考与独立预测结果 | adapters/anuga.py | 可核对的水情与预测事件 |
| 3 | 实现固定路线观测及匹配残差 | data.py | 带时间与预测版本的观测记录 |
| 4 | 实现区域联系、历史、衰减及掩码 | representation.py | 各对照表示及关键规则测试 |
| 5 | 实现统一诊断、配对评价与回放入口 | evaluation.py、pipeline.py | 可复核的信息增量比较 |
| 2A（与2同时） | 核对并实现原论文环境及策略底座 | adapters/pymarl.py 及后续模块 | 可运行的搜救闭环 |
| 7 | 开展同预算闭环对照 | 后续按需要扩展 | 行为机制与真实服务收益评价 |

每一步完成后再明确下一步的具体参数。当前配置中的 null 均表示尚未确定，不代表默认有效值。
