# 物理传播与行动尺度校准：运行前设计

当前40→80固定点复核通过，但此前8个有限数值配置内一致的离线改序机会仍只在零延迟保留，10秒延迟为零；20/30秒时域的旧物理核与新近性重合。不能据此直接开展收益确认。

本轮只做训练期设计筛查，不拟合P4/P5，不读取旧确认家族。使用旧训练编号最小的000—003四家族，避免沿用按正例选择的009/012/017/020作为全部设计依据。配置在首次积分前保存并由运行目录冻结源码、环境与哈希。

## 固定比较条件

- 纵向100/200/300米，横向100米；纵向床坡除以长度比例，保持总床面落差，横向脊不变。实际固定采样坐标同步缩放x，跨网格不变。
- 水动力输入仅为左边界固定[10,30]/[60,80]米区间的平滑脉冲；真实幅度0.1/0.2米均报告，名义探针幅度0.1米。180/240/300秒锚点全覆盖，10/20/10秒升/平/降。参考和名义基础轨迹相互独立。
- 网格40、2秒输出至390秒。100—310秒每10秒从同配置独立名义状态重启60秒预测，保留原始状态。足以明确匹配所有本轮可用历史记录的真实发布版本。
- 原32布局、两个候选顺序、锚点后0/6/12秒初始决策、每图边移动6秒、完整服务12秒、0.8米阈值、锚点后60秒截止。任务筛选只用锚点已发布名义预测的完整服务区间±5厘米；一般总体同时报告。
- 六个共同上游通道，目标无本地记录。离线可见性只检查5秒采样四相位、0/10秒延迟、60秒历史中实际已到达且被年龄分箱保留的源响应。无噪声配对参考变化≥1毫米只是预设必要条件诊断，不是在线检测器；后续方法比较保留0/2厘米噪声。

不同长度仍沿用每图边6秒，因此图边对应的物理位移和有效速度随长度/方向改变。这是明确的物理与任务尺度联合校准，不将条件间差异解释为单独改变空间长度的因果效应。同一条件下所有方法必须使用相同规划器、动作和时间预算。没有声称该简化运动模型已完成真实无人机动力学验证。

## 输出与筛选规则

保存所有共同区间、完整两个顺序计数、当前名义选序、临界掩码、源/目标名义响应标记、正负时滞、相位/延迟可见性和全部原始场。允许跨侧传播；不预先把地理分组当成完整水动力连通。

“脉冲专属机会”要求同一替代顺序在E1比冻结名义顺序好、在配对E0中并不更好。这样不能把持续偏差本来就能挽回的空间计为新增脉冲信息的机会。这个离线条件仍不证明模型实际可辨识事件或必定获益。

固定按长度升序、幅度升序选择第一个满足条件的候选：四家族各至少10个临界设计情境、至少2个非空锚点×边界单元；家族宏平均相对名义预测的有限动作上限至少4次服务/100情境；零延迟、四相位平均的可见脉冲专属机会至少2/100。E0/E1等权。临界家族为空时明确报告，不用真值补入。全部候选及每家族值同时发布。

这只是相对名义预测的乐观训练期筛查。通过后仍须新几何数值敏感性、强基线与P0—P5开发、独立精度先导中相对B*剩余空间的家族区间下界≥2/100、最后固定新确认。实际收益目标仍为1/100，不能以筛查通过替代完成。

积分预算最多504场（240条完整基础/脉冲/探针轨迹，264次60秒名义重启）。若六候选均未通过，报告原因，不自动添加长度或幅度直至出现正例。既有运行与阈值保持原样。

## 源码使用

写代码前已核对已有ANUGA域构造、固定边界/点位读取及FilterPy固定快照。此轮复用ANUGA求解、现有脉冲法、固定点权重和既有任务评分；新模块只声明物理尺度变体。FilterPy普通更新留到共同历史强基线阶段，未把LISFLOOD-HDAF的PCRaster流量同化直接冒称为二维水深同化。
