# 首轮边界评价冻结规格

在边界数据生成与评分前确定（当前四组短训练运行中）。所有模型按主验证集选择，边界测试不重新训练、选图、选模型或阈值。结构与K/T/年龄保持主配置。

1. 主留出事件：基础条件、观测延迟10s、延迟30s、噪声标准差0.05m、服务耗时24s（较紧）、接收阈值1.2m（较宽）。每项单独变动，其他条件保持不变。
2. 新增独立快涨水事件3个：涨率0.0065–0.009m/s，其他地形范围同主设置。
3. 新增高脊线事件3个：脊线高度0.65–0.85m、涨率同主设置。只称“脊线分隔”，是否水文弱连通根据原始输出事后诊断，不预设成立。

新增事件随机种子20261015，与主事件家族完全独立。正式模型执行关闭梯度增强；使用本地actor，不提供评分侧真值。

各条件按洪水家族和训练种子汇总，任务布局固定两份且所有方法共用。观测/窗口扰动是同一参考洪水的版本，不作为新的独立事件。跨条件不把它们当独立重复，分条件比较。

增加条件只是诊断失效边界，不追求调到正结果。无服务收益或小样本区间跨零时如实记录。
