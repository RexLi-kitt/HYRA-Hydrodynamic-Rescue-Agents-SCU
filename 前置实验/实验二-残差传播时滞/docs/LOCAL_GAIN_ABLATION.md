# 收益定位后的本地校正剖析

2026-10-15。探索性事后剖析；已查看主诊断、分层归因和四种平局规则结果。

动机：零延迟C1中，原固定首序下物理组较名义增加0.02252个服务/情境；同输入的连续水深余量平局规则下仅0.00826，自身历史组为0.00901。上游历史的预测MAE更低，但任务收益没有更高。下一步检验本地观测的何种成分负责收益，不继续调物理时滞核。

固定R5、D=0/10、4相位，沿用同训练/验证/内部诊断家族、同预测时刻与标签、同134输入槽和岭回归候选。新增4种表示：

- self_latest：只保留每个目标自身最近一条已到达原始观测、对应历史预测、年龄及缺失标记；其他历史槽清零。
- residual_latest：只保留自身最近的有符号版本匹配残差、年龄与缺失标记；不保留观测和历史预测各自的绝对值。
- residual_history：保留自身六个年龄箱的有符号版本匹配残差、年龄与缺失标记。
- full_latest：自身与三个上游源各保留最近一条已到达原始记录，检验长历史是否有独立用途。

另列不训练的residual_persistence：将最近一条自身有符号历史残差平移加到当前预测的整条未来曲线；缺失时不修正。它不是校准概率、同化或保证正确的传播模型。

所有方法同时使用原固定首序和预测完成数优先、最小预测服务余量次优的平局规则。后者只改变预测收益相同的顺序，不使用真值。分别报告全未来曲线MAE、家族等权实际服务差与剩余遗憾；不得因测试结果挑选唯一胜者。新增32个线性读出，每个3个候选；不新增水动力或策略训练。
