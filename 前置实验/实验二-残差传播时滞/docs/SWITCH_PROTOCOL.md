# V3：持续偏差与突发预测失配配对实验

冻结于生成新条件、读取新结果之前。用户授权“开始实验”。

只增加现有预测器的受控输入扰动，不增加在线GMRF、奖励、通信、安全控制器或主动推理算法。五组保持V2的共同原始历史、相同网络容量、奖励、服务失败恢复规则及训练预算（3种子，每模型120回合）。

沿用6训练、3验证、3测试洪水家族；每个家族生成constant与switch两个条件，真值逐元素相同。两个条件始终属于同一划分。由于这些真值已看过，本轮是配对诊断，不能称新盲留出验证。

constant预测输入增水率为真值驱动的0.75倍。switch在120s将此系数改成0.4，边界水位连续，只改变此后的斜率。独立名义状态从原120s名义状态续算，不使用真值或观测重置。120s之前已发布的预测完整保留，不提前知道改变；之后发布的预测使用已知的新输入。20s固定提前量残差最早在140s匹配到新版本。预测失配不是现实洪水突变。

训练轮流覆盖训练家族两个条件；模型只由两个条件的验证集均值选择，60/120回合选择且同分取最早。测试同一家族两个条件使用相同布局、起点、目标、训练种子。报告五组在两条件下的完成率、失败次数及B2配对差异，不筛选B2获胜的事件。条件翻倍不意味着独立洪水数量翻倍。

图联系验证按家族投票：同一家族两个条件均满足同号、|相关|≥0.5才计一票，至少2/3验证家族通过。开始执行时发现原代码按单条件计票，早期训练中断；最终结果使用修正后的完整新训练。

离线变化诊断使用固定左上5×5格点观测区域，每10s采样，保留有符号残差。这与移动回放路线不同：移动路线的重复访问可能间隔90s，无法在60s历史窗内形成3条记录。该固定区域用于先隔离时间变化的可辨识性，不代表无人机实际覆盖和全场表现。当前残差与该格点此前3条、60s内有效记录比较，先评分再更新历史；至少3条历史才评分。尺度下限0.02m，与0及0.02m观测噪声两条件配合检查。阈值取训练constant条件120s前分数99分位，验证/测试不调阈值。报告测试120s前误报、140—180s超过阈值比例及与constant同时间窗对照。该比例不是物理变化识别准确率、不是贝叶斯惊奇，也不作为在线输入或奖励。

沿用几何先生成、真值后评分的两目标访问顺序诊断，比较预测输入改变前后实际可补救差距。真值仅用于离线评分，不用于生成目标、路径或筛选训练场景。若机会仍稀疏或B2无稳定收益，照实报告。
