# 有效提前量与新近性对照：探索诊断

2026-10-15。使用已查看过的12个探索家族（6训练、3验证、3内部诊断），不属于新盲测。原20秒主指标和原阶段门槛不变，不回写旧运行。系统本地Python，CPU读出，无环境安装或策略训练。

## 预先固定的诊断

1. 对原图每条边及80—240秒、间隔10秒的决策时刻，记录最新已到达观测年龄、缺失、名义传播时间减观测年龄L，以及L减0/6秒行动等待的余量。观测年龄已经包含通信延迟，不重复扣除。预测目标固定在当前t+τ，因此目标覆盖使用L≥τ且L>行动等待；另记L−τ，不将τ与等待重复扣减。统计提前量为10/20/30秒时的边覆盖、目标至少一条边覆盖。此量只表示名义到达时间的几何余量，不是残差可预测性的严格上界，也不是实际报警提前量。
2. 保留原I1共同趋势、I2均匀历史、I3物理核；加入同10秒高斯核、中心固定0的新近性对照。再做归一化版本：物理核、零中心核、均匀核、错位核先在每条边的历史内归一化，再用固定边权汇总，仅对有支持的边统一归一，避免同时改变空间源权重；后三个字段统一为残差均值、与核无关的可用历史支持度、与核无关的历史平均年龄。各方法35维、相同源/历史/共同趋势、同一ridge读出和正则候选0.1/1/10，标准化只用训练、正则只用验证。
3. 固定截面和原轮询相位，噪声0/0.02m×延迟0/10秒；另在无噪声、无延迟下加入轮询相位1/2/3。同一相位内各方法完全共用记录，平移相位不提高观测预算。相位不是新独立家族；汇总先在家族内平均四相位，再跨家族统计。当前仍为截面轮询近似，不宣称满足飞行运动约束。
4. 方向审计只用训练家族名义求解器响应确定早期/较晚窗口，再用于内部诊断分层；不按内部诊断真值选窗口。不把反向截面自动当无信息负对照，也不把较晚响应直接归因为边界反射。所有时段主结果保留。

## 解释与推进条件

所有10/20/30秒、稳定/局部扰动/共同偏差条件完整报告，不能只选收益最大窗口。配对误差按家族等权，3个家族的区间仅作探索；噪声仅沿用一次实现，不能当充分鲁棒性证明。

诊断性推进条件预先固定为：C1无噪声/无延迟、20秒提前量，归一化物理核相对共同趋势、归一化均匀核、归一化零中心核、归一化错位核，在固定截面及四相位轮询的家族内平均上均至少降低5% MAE，至少2/3家族改善，家族配对差区间上界小于0。该条件用于防止以新近性收益冒充物理时滞收益，不替代原阶段结果，也不是天然科学阈值。

只有该条件成立才进入两目标临界施救诊断，布局依据名义预测、几何与服务耗时生成；否则明确记录未进入原因。正式36家族数据与大规模QMIX训练均不启动。时间尺度诊断不靠改大扰动或事后调整主提前量获得通过。
