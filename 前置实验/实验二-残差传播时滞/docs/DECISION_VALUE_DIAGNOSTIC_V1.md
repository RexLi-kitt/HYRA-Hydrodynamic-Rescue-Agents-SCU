# 残差信息到救援选择：探索协议 V1

2026-10-15。用户授权执行后的新探索协议；在新结果计算前写入。
复用已查看的12家族（6训练、3验证、3内部诊断）、36个C0/C1/C2事件。
不属于盲测，不更改原20秒主指标或原门槛失败结论，不训练QMIX。

## 范围与任务定义

1. 先复现旧32个一般布局的有限两顺序机会，增加32个目标限于已校准目标截面的布局。
   地图、起点、目标由固定种子及几何生成，不依赖真实水情、残差、候选模型表现。
   截面布局只检验已校准区域；不能代表全域随机任务。
2. 单机、已知地图、已知两目标、资源足够；沿静态最短路走，6秒/步、12秒服务、0.8米阈值。
   仅完整服务成功计数；失败在6秒动作节拍结束时释放，不自动重复启动。
   路径中间水情不阻止飞行，遵循既有简化子问题，不是完整多机环境。
3. 原始一般布局机会按旧60秒发布时域检查复现；截面任务与新模型统一使用50秒安全时域。
   每个决策时刻最新版本通常已经发布0到8秒，50秒保证不越过其60秒预测范围。
   所有候选顺序最慢完整耗时和300秒任务结束限制在看真值之前检查。
4. 每个布局在24到240秒、步长6秒生成初始情境。名义预测选序，平局选固定首序。
   从该初始顺序的最短路径上，枚举首次服务开始之前的6秒决策节点。
   在同一节点比较当前名义预测和残差模型的两种剩余顺序，参考真值只评分。
   这不是独立运行的新闭环策略；多个节点不可累加成一个任务的救援收益。
   “最后可改时刻”仅为该有限前缀上最后仍有正可挽回差值的采样节点，非全局硬期限。

## 观测和新版本匹配契约

固定24个监测格点的合成观测，不假设无人机能实现相同再访频率。
再访R={2,5,10,20,40}秒；延迟D={0,10}秒；相位={0,1/4,1/2,3/4}个周期。
首观测20+相位*R，末观测不超过300秒。每次观测24个格点；必须记录总观测数。
较密采样意味着成本增加，本轮不声称同预算主动观测收益。

使用观测有效时刻s至少20秒前已发布的最近真实版本：f=max{r:r<=s-20}。
只在该版本有效时域内插值水深，记录actual_lead=s-f（约20到30秒）。
不在发布版本之间插值，不虚构2/5秒发布；缺版本记录缺失，不能填零准确残差。
真值和预测有效时间在既有输出之间线性插值，无新增水动力精度验证。
该契约与旧“恰好20秒”不同；不能把新旧跨契约差异归于采样率。
10秒、零相位必须复现旧有效版本与残差。

## 固定比较组与模型

所有组输入槽位同维、同岭回归族、同候选正则{0.1,1,10}，不改变环境奖励。
历史固定为60秒内6个10秒年龄箱，每箱保留最新已到达有效记录。
原始历史包含观测、对应预测、年龄、缺失标记；不使用“最近六条”造成时长漂移。
共同输入包含目标当前发布版本未来0到50秒、间隔2秒的预测曲线、坐标和时刻。

- raw_self：目标自身原始历史；上游历史及附加表征槽置零，作为信息可见性诊断。
- raw_full：自身与同3个上游源的完整分箱原始历史，附加槽置零。
- recent/physical/uniform/wrong：保留raw_full全部历史，只改变额外残差汇总。

汇总仅使用raw_full中同样的六箱记录，不额外读取未提供的历史。
在tau={6,12,20}秒分别提供汇总，合计9个附加槽；每源先归一化再用冻结空间权重。
支持度和平均年龄不随核改变。核宽10秒；physical中心max(T-tau,0)，
recent中心0；uniform等权；wrong中心(physical中心+20)模40秒。
这是新多时域表征探索，不是对旧20秒单时域实验的重命名。
raw_full与表征组之间测试有限模型的表征利用能力，残差不是新增原始信息。

多输出岭回归预测当前发布版本未来0到50秒整条误差曲线，每2秒一个输出。
仅训练家族拟合标准化与参数；每组正则仅按验证家族平均误差选择。
参考误差定义锁定决策时刻已发布版本，绝不使用未来发布版本。
输出加回当前发布曲线（负水深截为0），用原有整段服务评分选择顺序。
不把确定性阈值评分当校准概率，不声称测得互信息或贝叶斯VoI。

完整时间/核可辨识扫描：全部40个R/D/相位条件，无噪声。
决策读出主条件：R=5，D=0/10，各4相位。
辅助条件：R=10/40，D=0/10，零相位，共12组观测条件。
每组6模型，共72个多输出CPU读出（每模型3个正则候选）。
噪声、集成模型、LPM、主动观测和QMIX留待这一链路有证据后单独立项。

## 记录、统计与解释

记录每个情境/节点的源观测有效时间、到达时间、版本、实际提前量、年龄，
当前发布版本、预测顺序、真实两顺序收益、收益差、有限候选上界、最后可改节点。
完整报告C0/C1/C2；一般布局与截面布局分开；训练/验证与内部诊断分开。
主要任务比较只使用初始情境的决策，前缀节点用于机制诊断，不能膨胀样本量。
相位先在家族内平均，家族等权；内部诊断独立家族为3个。
保留正/零/负收益、排除数量、首次响应前后分层（事件元数据仅用于离线标注）。
不将可见记录或名义时间余量自动判为有用信息，不将覆盖率与机会比例相乘。

推进建议而非统计成功宣告：若一般/截面布局几乎无可挽回损失，先报告任务上界；
若有机会但模型不能改善初始选择，则停止接入QMIX，分析信息/学习/时限瓶颈。
只有家族配对任务增益及风险可接受、优于原始历史与新近性对照，才提出独立确认实验。
本轮即使为正，也不自动启动正式36家族测试或QMIX。
