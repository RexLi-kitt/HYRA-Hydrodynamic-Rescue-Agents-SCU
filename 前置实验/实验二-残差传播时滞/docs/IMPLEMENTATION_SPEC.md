## 论文继承与实现假设

基础10×10网格、4无人机、5目标、50同步动作、5×5探测窗口，奖励系数沿用论文。CNN两层16通道、嵌入32、GRU64、时间正弦编码32，混合宽32；各组固定同维输入。固定u为归一化全1向量。每时间步对批次×无人机梯度范数min-max；相等则0，增强不进行二阶求导。回放/目标/混合/TD训练直接调用PyMARL，依赖接口适配写在项目内。

地形SAR连接8邻域，行和0.35；探索切除观测节点相关边，观测值以均值边界保存，epsilon回合固定。信号SAR在真实非障碍上连接，接近目标权重增强后行归一化0.35；均值1、噪声0.03，lambda=2格，乘原文距离衰减。信号仅在传感窗口读出，探索图保存已获得值，隐藏目标仅供仿真信号生成，不向在线策略传递目标真值。此处均为最小实现假设。

越界/障碍停留并罚1。多人到同格或交换位置时全部相关移动停留并罚1；斜向不允许穿障碍角。没有额外停留动作。处于服务中自动停留、忽略动作。动态服务自动触发，先到者按无人机编号锁定目标，其他无人机不能同时服务该目标。失败释放锁，可再次尝试；成功扣除1份物资，每无人机初始2份。无物资可继续探索。

任务未知总数不进入在线特征；已发现目标、服务状态、已完成位置可共享。训练state允许真值地图及当前水深；执行网络接口无state。探索地图共享权限各组一致。

## HyRA新增设定（验证选择，非真实灾害参数）

- 坐标本地平面米、地形高程基准任意固定零点、水深=stage-elevation。
- 100m×100m域，10m任务格；ANUGA三角形网格与任务格一一查询最近质心，并保存索引、最大映射距离。物理网格与任务障碍分开，障碍只限制无人机移动，不伪装为水动力建筑。
- 洪水输出每2s，预报每10s独立滚动发布，固定残差提前量20s，预测时域60s；各起报从独立名义预测轨迹的状态复制，不读取参考未来或观测。
- 初始水深0.15m；西侧涨水边界；参考入流涨水率随机化；预测涨水率系统性低估25%。地形坡度与横向脊线各事件随机化。只有这一种偏差。
- 主任务正交与斜向每同步步均6s（各组相同，速度因方向略不同）；服务12s。接收条件为整个区间水深<=0.8m，失败时间照计。并非死亡率或禁飞条件。
- 成功奖励5/进入目标前移动格距离，最低距离1防止零除；团队惩罚以步索引max(t,1)，截断下界-5；超时所有未完成包括机会失效目标。
- 观测每10s，局部5×5，首轮无噪声/延迟；任务动作时刻与采样时刻分别推进。回放固定稀疏扫描路线、每次4格。K=2，T=30s，最大年龄60s，最多3联系（包含self），候选8邻域；B1相同稀疏上限/self规则。
- 完整家族级划分：首轮6训练、3验证、3测试；后续新增完整边界事件，测试不可拟合。三个训练种子、四组各独立训练；首轮120回合/组/种子、batch4、buffer64、目标周期20，最后与第60回合模型仅按验证真实收益选择。论文训练1e5回合，预算缩小是试运行限制。
- 离线统一岭回归读出，所有组同样4K×全图槽位＋位置/时间，拟合训练、验证仅选统一正则值；严重低估阈值0.15m先冻结。读出不进入策略。

未承诺：洪水单调性、联系跨事件稳定、结构收益、时间收益或提升百分比。首轮水文变化与目标服务余量通过离线检查报告；如全部宽松/全部不可完成，应单独报告试运行设计不足，禁止用测试结果调参后仍称留出。

## 依赖与边界

系统Python3.14.2、PyTorch2.14.0+cu130、RTX5060 Laptop GPU；旧MSVCP DLL遮蔽已修复。ANUGA官方4.0.1替代下载开发commit用于串行求解，pymetis已在本机编译并安装。未改无关仓库，未发布远程。

补充冻结实现选择：PyMARL回放索引在项目适配器中转为tuple；有限50步任务的超时视为终止。目标网络不启用梯度增强，保持执行表征；这属于原文未明确的实现选择。模型验证规则为完成服务数量均值最大，平局选较早检查点。所有组同样选第60/120回合模型。输入为33×5×5；回放诊断取4K本区特征＋全图5×5均值池化＋坐标/时间（211维），各组同槽位、同岭回归正则搜索，并按四组验证MAE均值选择共同正则值。

区域联系先用训练样本估计，再按预定验证条件保留：3个验证事件至少2个同符号且|相关|>=0.5；测试不参与。B1按B2每行实际保留边数配置距离联系，self规则一致。图共用分母归一化。共同入流偏差用去全局均值相关与全局均值残差参考单独诊断，不能把强原始相关直接解释为稳定传播。

移动完成前的采样采用前一决策位置，完成时才使用新位置；服务机会失效状态在评分侧单独记录，不能把未观测区域真值失效标记泄露给actor。
