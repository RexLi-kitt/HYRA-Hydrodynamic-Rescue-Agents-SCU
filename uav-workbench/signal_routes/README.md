# 三路线信号后验研究

当前范围：固定人员、E2搜救主评、E1零信号回归。独立实现，不改写原信号生成器和历史实验。

## 一键执行与恢复

在无人机工作台目录运行：

```powershell
python -u -B tools/finalize_signal_routes_study.py --run-study --workers 4
```

同一命令可从最近完成阶段及检查点恢复；恢复前先核实旧控制器及其训练子进程已经退出。来源、配置或数据摘要变化时拒绝混用旧结果。现行v2训练/确认进度位于 `generated/signal-routes-20261027-v2/status.json`，完整报告和独立验收进度位于同目录 `finalization-status.json`，各子任务日志在 `logs/`，最终输出 `report.md` 和 `report.json`。初版输出和源码快照保留在原目录，标为superseded，不混入正式比较。

此入口包含独立父地形水情配对的合成零关联诊断；低级模块命令主要供分阶段调试。不得同时启动两个控制器。运行耗时取决于本机实测速度，完整训练完成前不把工程检查或开发集诊断称为正式确认结果。

`tools/run_signal_routes_study.py`是训练和确认入口；完整入口在它结束后生成失败分类、删失时间、分机制消融和图表，再独立复算9组比较、区间与Holm校正，并使用原环境重放全部1728条保存动作、重跑216项规则评价。只有独立 `completion-audit.json` 通过且绑定当前报告摘要，完整验收才通过。已有训练/确认结果时，运行完整入口会直接进入报告与验收。

外部结果导出适配器仅将NumPy坐标转换成标准JSON，仍拒绝非有限数；回归证据见 `result-io-regression.json`。它不修改模型输入、动作、估计器或冻结训练源码。

## 接口与模型

`SignalBeliefEstimator.reset/update/posterior`只接受合法已到达记录。原始测量、人员发现、施救条件不受后验估计影响。策略保留21通道，仅替换局部/池化信号通道3、7；E1直接返回严格零信号。

- R1：水情调制非对称SAR系数，整体高斯精度仍对称正定。
- R2：只改变条件均值；使用公开底床加观测水深的水面坡度（按实际米制邻接距离差分），四项特征仅用训练记录计算均值和标准差。缺测或干燥边不提供水面坡度。
- R3：以半正定二次残差耦合未知结构与信号。
- Braw/Bpost：原始信号记录/无物理后验。
- C1–C3：对应路线的联合水情置乱控制，训练和评价采用相同规则。

参数仅用训练记录拟合；条件信号负对数似然包括对数行列式。估计器在强化学习之前冻结，首轮不叠加数据或SWE辅助损失。R1与二次CRF可以数学等价，不将其名称差异当创新证据。

R2的速度和坡度均取幅值，属于标量协变量均值校正。开发记录中的36项R2/C2流向翻转检查已验证，即使拟合参数非零，翻转u/v也不改变后验；本轮R2不能证明上游→下游方向传播。证据见 `mean-direction-diagnostic.json`。

## 固定实验设计

6个训练、3个开发、8个新确认父地形。慢涨/快涨单峰用于训练和开发，确认另含未见双峰来水。每事件900秒真实求解帧、20×20原格、5米格距。开发规则在900/600/450秒中选择最长可判别时限；若不满足预登记门槛，900秒结果只作描述性比较。

8组×128回合工程检查之后，8组×3种子×1024回合正式训练，共24项；开发选模点256/512/1024。封存全部模型之后才打开确认集，执行1728个模型回放和216个规则评价；模型回放重新执行动作核对原始观测、事件、返回值和最终actor视图。统计按8个父地形聚合，三项主要比较做Holm校正。

## 检查命令

```powershell
python -B -m signal_routes.checks
python -B -m signal_routes.run status
python -B tools/audit_signal_routes_study.py selftest
```

完整研究和独立重放审计通过后，再运行交付字段复核：

```powershell
python -B tools/audit_signal_routes_delivery.py
```

此复核独立检查1944行扩展CSV、1728条模型回合的失败分类和删失时间、12项分机制配对区间、684条开发方向诊断、36项均值路线流向翻转及源码/工具快照，并生成 `delivery-audit.json`。不完整研究会在读取确认性能之前被拒绝。图表仍需打开检查可读性。

开发集方向诊断保存在 `independent-direction-diagnostics.json` 及其说明文件。它显式区分工程上的非零方向响应能力和训练参数实际是否活跃；零退化不能写成已学得方向性。`frozen-sources/`、`external-sources/`、`runtime.json` 与 `reproduction-manifest.json` 保存源码、运行环境及摘要。当前数据清单引用初版目录内未评分的同批物理事件，复现时需保留这些数据包。

原环境没有直接水情—信号调制，但目标选址限制会产生位置先验。合成衰减和方向响应诊断不代表真实信号物理。预算内未改善、退化或不确定结果均保留；不把估计改善写成施救收益。
