- `flood1km/learners.py`：六种方法的候选实现。
- `flood1km/train.py`：单方法试训、初末验证、日志、检查点与断点恢复。
- `flood1km/benchmark.py`：64 回合规则基线成本检查。
- `flood1km/orchestrate.py`：测试→场景→成本检查→六种算法依次试训；任一阶段失败停止，不自动重试。
