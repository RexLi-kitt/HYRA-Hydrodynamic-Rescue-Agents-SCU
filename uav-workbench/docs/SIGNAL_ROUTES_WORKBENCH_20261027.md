# 工作台三路径入口

入口为 http://127.0.0.1:8767/。刷新页面后，在左侧“研究方案”选择“三路径信号建模 · R1 / R2 / R3”，即可选择路径一有向SAR、路径二物理协变量均值、路径三跨层CRF。共同基线Braw/Bpost及C1/C2/C3置乱对照也在同一列表。

切换方案会选择“探索—搜救”和“模型运行”。三路径仅有这一任务的冻结模型，不能用它们替代纯探索模型。场景列表提供三路径研究的训练和开发过程，确认父地形不开放为交互场景。任务保持100米、20×20格、两机、900秒；场景种子与模型训练种子分别选择。

点击“运行所选组模型”，回放显示实际使用的路径、训练种子、选中回合、权重摘要和参数摘要。信号图展示策略实际使用的后验均值；原始观测、人员发现、施救与时间戳保持原任务语义。规则模式明确作为独立规则核查记录。

工作台使用已完成研究的24个封存模型，并检查完整审计、交付复核、冻结参数、源代码和模型权重摘要。本次网页适配不修改冻结研究包。真实开发轨迹已逐项对比原研究入口的动作、观测、事件与收益；HTTP验证覆盖三条路径和原双任务入口。

“可运行”不表示物理收益已证实。本轮R1/R3拟合为零耦合，R2采用标量水情特征；结果仅作登记范围内的描述性解释。交互回放不添加到正式确认结果。

相关实现为 `console_signal_routes_contract.py`、`console_signal_routes_runner.py` 和现行页面 `console-static/workbench-scale100.*`。回归检查为 `console_signal_routes_checks.py`、`console_scale100_checks.py`、`console_scale100_http_checks.py`。
