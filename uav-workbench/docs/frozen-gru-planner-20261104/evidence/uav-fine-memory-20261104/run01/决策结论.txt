所有训练及116场评测完成，运行1816.469秒；无新长跑队列。
新CAL8父场/320人：完整覆盖224(70%)，flow217(67.8125%)，旧GRU180(56.25%)。
粗输入16轮两种子235/238，32轮219/230；细格16轮235/255，32轮228/238；混合32轮223/243。
CAL依预先规则两个种子均选细格16：73.4375%与79.6875%，比覆盖规划+3.4375、+9.6875个百分点。不能只报最好一个，也不能把相对旧模型的改进全部归于细格特征，因为训练父场/接入方式等也已改变。
同32轮消融细格比粗输入多9人/8人，父场配对95%区间均跨零；是值得复核的信号，不是稳定效果证明。

CAL所有方法全员场0；所选细格第一个种子>=95%人数场1/8，第二个0/8；未达到稳定15个百分点场景优势，也未达到85–95%人数目标。
失败仍以截止前未发现为主：所选两模型失败85/65人，其中83/63人截止前未见。实际再漂浮全部0，未验证针对再漂浮情形的策略收益。

决定：
1. 保留两份细格16轮权重和强规划，生产默认不变，不因CAL最高值单独宣传部署可靠性。
2. 不继续此人数Poisson预测器的64/128/1024盲加训；混合轨迹不作为已有效改进升级。
3. 下一可证伪单元转向任务目标对齐：候选搜索片段的后续按时投放收益监督，先在FIT少量状态检查分支收益和成本，必要时否决。沿用已有论文计划，区别于旧60s已知目标改派。
4. 该单元开始前核验分支随机事件一致、原规划分支回放等同、未来真值仅训练标签使用；保留线性同输入对照，避免复杂度掩盖无收益。
5. 若要独立确认细格优势，补较宽粗输入容量对照/第三训练种子及新的冻结测试。当前8CAL已用于选模，不当最终测试。
本轮没有改视野/窗口/水情阈值/地图生成分布以追求好看成绩，未使用禁用六算法，未推送。
