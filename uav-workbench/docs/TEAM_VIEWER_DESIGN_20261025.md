# 双机回放页设计

用途是人类逐时刻核验已有双机回放：同一几何、同一时间并排展示实际水情与共享认知，不在页面启动训练或改写记录。沿用三个并列工作台，新增页面只在无人机目录下。

颜色：云灰#edf3f8作页面背景，深蓝墨#193849作文字，水蓝#3d84b8表示淹没，灰蓝#788b96表示未知，橙色#b85629与紫色#6554a6区分两机。干燥用浅底。颜色表达水情/权限/无人机身份，不用于无含义的装饰。

字体：中文Microsoft YaHei UI，标题20–28px、正文14–16px；数值与HyRA字标使用Bahnschrift。所有信息左对齐，控制条跨两张地图，矩形像素地图为主要视觉元素，不以宣传区或大数字占用首屏。

```text
HyRA 双机回放                         载入工程演示  打开本地回放
播放/上一帧/下一帧   [同一物理时钟滑块]   000 / 600秒
实际水情                               共享认知
[ 地图 + 两机路径 ]                    [ 地图 + 实际观测边界 ]
            图例与显示开关
当前正确覆盖     未知     已知区错误     距离/转向/碰撞
来源、方法、阈值与采样周期；离线评价中的真值不作为策略输入
```

复核：这是一页时空对照工具，不是通用管理看板。地图像素、航向箭头、同一时间滑块和保留时间戳是核心。省去通用卡片网格、渐变、装饰图标和自动动效。移动端两图纵排，键盘可操作滑块和按钮，焦点清晰，默认不播放。

最终验收需要实际600秒回放、起点/中间/终点、播放/暂停、逐帧、文件校验与窄屏截图。所有界面修改位于独立team-viewer与工具入口，不修改冻结科研实现。
