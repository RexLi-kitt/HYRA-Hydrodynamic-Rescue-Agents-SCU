# 六算法结果与回放接入

入口：现有工作台顶部“六算法研究与回放”，或 `http://127.0.0.1:8767/six-study`。

## 使用

1. 正式结果表显示6个单模型、15种组合、纯规划与随机动作对照。选中回合来自测试前的开发验证，不按最终测试重新选模。0回合是该适配阶段继承的初始权重，不代表未训练的随机模型。
2. 在“封存测试动作重放”中选择模型、主/压力场景、完整/无覆盖设置及成功/失败记录。全部5630条记录保留。点击加载后，由原环境重算封存动作，逐步核验位置与事件，再核验终态和正式指标。
3. 在“最佳权重 · 开发场景演示”中选择冻结检查点与6个已有开发水场之一。单模型使用全队同模型，组合提供两种分工。使用固定演示人员布局770003、原覆盖规划与服务控制、确定性推理，不训练、不重选模。
4. 播放或拖动时间轴查看4机航迹、当时已发现人员、服务进度、首次覆盖及冲突。默认只显示当时观测记忆；可勾选当前水情真值作回放核查。地图按原100×100格、5秒步长、1公里区域绘制，无空间插值。显示水深色阶不作为安全通行阈值。
5. “下载当前完整回放”导出帧、指标、来源哈希。演示保存到 `generated/six-study/runs/<id>/`，不会修改正式结果或权重。

## 本地运行资料

统计使用仓库 `docs/strict-eval-20261101` 的封存文本，没有本地权重时仍可查看。
回放和模型演示额外需要原研究档案：水场、动作轨迹、21个冻结检查点、原训练/控制器配套源码与既有学习环境。它们没有随Git发布；网页不接收任意文件路径或上传权重。当前接入是本机档案适配，不声称干净克隆即可重现实验。

已有完整原档案的机器，可运行：

```powershell
python tools/configure_six_study.py --archive-root <包含各uav研究目录的原档案根目录>
$env:HYRA_LEARNING_PYTHON = '<已有学习环境的python.exe>'
python -B -m hyra_workbench --port 8767
```

适配器沿用归档中的绝对路径；移动档案后不能仅修改路径并沿用旧摘要，需单独编写并核验迁移适配。配置写入被Git忽略的 `generated/six-study/local.json`，或由 `HYRA_SIX_CONFIG` 指定。配置会核验原源码、检查点，记录清单与轨迹摘要；worker每次运行再核验，来源变化拒绝运行。PyTorch只反序列化本机登记且哈希一致的研究检查点。
