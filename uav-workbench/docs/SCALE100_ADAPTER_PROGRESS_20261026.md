# 100米实验：工作台接入准备与评价接续

本记录是中间进展，不是正式效果结论。正式实验仍为两个任务、六组方法、三个训练种子，共36项；每项1024回合、1021次更新，100×100米、两机、900秒。训练配置及冻结源码未改变。

## 本次完成

- `console_scale100_contract.py`：纯标准库接口，兼容现有Python3.12网页服务，不在服务端导入Torch。只列出训练/开发场景；正式留出场景不进入交互开发列表。场景种子与训练种子分别保存，默认训练种子统一为11。
- `console_scale100_runner.py`：独立Python3.14推理进程，使用正式100米环境和21通道八动作模型，不调用旧环境的结果汇总函数。两个任务均可保存完整回放；规则结果实际组别为空。模型发布前接口拒绝运行，开发验证只有独立CLI入口。
- 六次完整开发回放：E1/E2 × 水情规则、D开发模型、P开发模型；每次900秒、181帧、362条真实传感记录、180次联合决策。保存文件与内存对象逐项相同，全部通过独立运动、观测、输入权限、施救审计。证据在 `generated/scale100-console-validation/20261026-v1/validation.json`，不计入正式结果。
- `console_scale100_checks.py`：7项通过，覆盖轻量服务导入、全部12种任务/组别配置、规则归属、错误环境拒绝、数据摘要、未发布模型拒绝和留出数据隔离。
- `scale100_release_audit.py`：正式发布前重放全部252项记录，逐步核对记录动作与登记模型/规则一致，再重建观测、轨迹、事件和21通道输入，复核指标与按父场景等权聚合。另核对36项完整预算、同种子初始化、选模规则及辅助共享梯度诊断；不会因为效果不佳重新选择或调参。
- `scale100_release_checks.py`：7项通过。真实开发模型/规则可复现，错误模型、篡改动作/观测/归属会被拒绝，训练未完禁止发布复核。已完成首批3个正式任务的预算与选模完整性也通过检查。
