# 六模型15组联动训练与公平初筛协议

2026-11-01，依据用户最新要求：所有允许模型先参加两两组合，不因单模型表现不佳提前排除；计算量较大时先64轮。

## 全部候选

六种模型为HAPPO、HATRPO、HASAC、MAAC、MAT、COMA，共C(6,2)=15组，不考虑重复顺序。每组交换两种无人机分工，避免将A+B与B+A重复计数组数。

## 初始化与任务固定

HATRPO使用既有512轮版本，其余五种使用既有256轮版本。单模型较差的HAPPO/MAT/COMA也保留参与，不另挑容易的场景。原模型、原三组队列和所有不利成绩保留。

复用已经校验的16训练、6验证合成父水场，不重新生成同配置水场。环境仍为四机、1km、20人、300个5秒联合步；服务规则、覆盖范围、奖励、运动和冲突判定不改。每次验证为6水场×2布局×2分工×（2随机动作种子＋1固定动作）＝72回放。旧/新父场、随机/固定和两分工结果分列；72回放不是72独立洪水事件。

自动服务、受阻重试和覆盖补漏与上一联动协议一致：规则在网络采样前给出单选动作约束，强制动作不记为自由策略动作；只读取公开的当前位置和已观测历史，不读取未来洪水或未发现人员。

## 联合训练兼容办法

两种模型共同控制同一环境，各负责两架无人机，每16回合交换分工。新增公开角色输入采用零初始化；旧优化器和经验缓存不继承到全新组合。父模型历史回合、本轮共同回合及各成员参数更新次数分开记录。

- 原HATRPO＋HASAC、HATRPO＋MAAC、HASAC＋MAAC三种使用原控制与更新函数，启动检查核对动作流等价后复用，不反复训练。
- HAPPO/HATRPO/MAT各使用自己的价值估计。只有一个使用新轨迹更新的模型时，每两回合更新该成员；有两个时，按两回合块交替更新一个成员，另一个保持不变；下一块重新采样，不将更新前轨迹作为伙伴的新轨迹再用。
- COMA保留其他成员实际动作进行反事实基线计算。未负责角色及没有自由动作的独立策略网络不执行优化器步，避免历史动量误改未负责角色。
- MAT的动作解码条件是前面无人机实际已选择的动作，不使用未执行的私有提案；共享网络只在负责的自由动作上计算策略损失，价值损失仍来自同一任务。
- HASAC/MAAC使用混合队友产生下一步动作。伙伴含MAT时，对候选动作重新计算后续因果动作；这是有记录的研究适配，不声称继承原论文的单调改进保证。

## 预算、筛选和后续

首轮15×64＝960共同回合。旧首组256轮的实测耗时已在数分钟量级，扩大15组并包含Transformer及完整验证会显著增加成本，因此先64，避免直接投入15×256的长队列。

1. 全15组均完成64轮后一起排名，仅允许使用0/64检查点。提前训练超过64轮的组合，其128/192/256成绩不得进入此次初筛。
2. 取前5组继续到本轮累计256轮，再取前2组继续到1024轮。
3. 排名沿用：先少违反旧/新×随机/固定分层平均潜在冲突/步≤0.02的组数，再比较完整任务、人员服务、较差分工服务、覆盖、较低冲突、较短截断步数。同分按组合名固定排序。每个预算内保留最佳；最佳仍为0时，必须说明没有证明训练收益。
4. 2048须同时满足768→896和896→1024连续改善：完整任务和人员服务不下降，覆盖下降不超过0.001，各分层冲突≤0.02、单回放冲突≤10；有任务比例至少1/n、服务0.005、覆盖0.005的收益之一，或任务质量不降且平均步数减少至少5；同时1024较256有收益、最佳版本在256之后。
5. 首轮64暂不增加关闭补漏的额外验证；入围256的组合补做相同权重0/256关闭补漏对照，区分规则收益和训练收益。50场封存测试不使用；三训练种子确认留待后续，当前不能作泛化或显著性结论。

本队列比较预算上限5504共同回合：15×64＋5×192＋2×768＋2×1024，包含可复用前缀，不按两成员翻倍。旧队列超过本次筛选预算的历史训练另行保留；只在组合晋级后复用相应后续前缀，不制造额外训练收益。

## 停止、核验与交付

旧三组队列已保存后停止：HATRPO＋HASAC实际完成256，HATRPO＋MAAC完成2，HASAC＋MAAC未开始。新队列单CPU两线程串行，不使用子代理、不启动第二重负载。

启动核验包括六个父策略补维等价、15组合两个成员实际更新、角色所有权、检查点优化器/缓存/随机状态精确恢复、原三组动作流等价、MAT因果动作前缀。原强制动作合法性与已观测覆盖边界断言继续执行。缓存迁移同时保留原协议哈希、原检查点哈希与迁移检查点哈希。

每64轮保存完整状态，64筛选全量验证0/64；256阶段每64验证，之后每128验证，全部末态和轨迹保留。人工停止在完整更新块保存；数值、运行、完整性问题即停，不自动重试或删除失败。阶段边界低于8GiB空闲空间或超过4小时不再启动下一阶段。

outputs与项目docs双份保存源码、协议、全量场次、报告和来源/配置哈希；大型水场和检查点由live-run指向完整路径。原项目和默认不改，回退为停止隔离入口。不会自动推送、外发或安装软件。排名入围是研究筛选，不是现场或工程验收通过。
