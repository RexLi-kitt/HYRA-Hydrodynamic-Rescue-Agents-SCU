# 正式检查点的晚期辅助梯度复核

这是一项只读补充诊断，不改变正式训练或模型选择，不替代留出任务评价。

## 为什么补做

冻结的 `scale100_aux_resilient.py` 只在更新1、32、128、253记录共享梯度，对应回合4、35、131、256。正式预算后来固定为1024回合，因此“最后一次日志中的梯度”实际只到第256回合。已有报告工具的用语是“最后记录”，但该证据不能单独证明最终保存的权重仍具有辅助梯度路径。

不修改正在训练的源码，也不重新训练。新增 `scale100_checkpoint_mechanism.py` 在每个已完成D/P任务的两种实际权重上独立测量：开发集选中的检查点，以及第1024回合最终检查点；若两者摘要相同可复用计算，仍分别记录归属。

## 诊断条件

只加载已登记的三个fit父场景，固定场景种子11，在同一水情规则参考轨迹的0、300、600、900秒取样，共12个采样状态。actor只接收合法观测和已有循环状态；训练标签只在离线构造损失时使用。

分别计算数据损失、实际内部短步物理损失到潜在状态、CNN、图像编码层和GRU的梯度范数。每个采样决策的上一循环状态固定，因此测量的是该步输入/GRU路径，不重建全部历史时序梯度。记录非零损失却零共享梯度的状态，不强制实际结果必须为正。

没有优化器、参数更新或`.backward()`累积。每次完整探测前后比对内存模型张量摘要，并确认所有参数的`.grad`为空。未知区预测不写回观测，也不读取留出场景字段。原数据文件的摘要校验仍按正式方案执行。

LeakyReLU下全部预激活为负不等于死神经元；因此诊断以实际梯度判断连接。对D计算的物理梯度只是潜在连接，D训练没有使用物理损失，不能据此把D说成物理辅助方法。
