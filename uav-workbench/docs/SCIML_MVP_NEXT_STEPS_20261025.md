# Sur-QMIX 与物理约束水情模型：下一步实施草案

日期：2026-10-25。状态：设计草案，不是已冻结预登记，也不是实验结果。用户已授权每三小时继续开展这一独立方向；原来两轮 P3 的预算、留出与源码冻结保持不变。

## 研究问题和首轮边界

在相同执行观测、训练事件和预算下，水动力物理约束的短时预测辅助任务，能否改善 Sur-QMIX 在动态洪水中的协同观测与回访效果？

辅助分支学习水情演化，因此明确属于世界模型的动力学部分。首轮用它辅助策略表征，不增加模型内行动搜索、虚拟轨迹训练、多步规划或替代现有水动力求解器。若以后使用这些功能，应另外登记，不能混作本轮机制。

水情演化与观测生成分别建模：无人机动作改变位置、朝向和获得的观测，不直接改变洪水。不能把无人机动作对观测的影响错误拟合成动作对水流的控制。

## 1. 收尾已有 P3，保留独立账目

核实实际进程后接续第二轮，完成新留出评分、严格 A1 实际缓存审计、输入权限、同预算、地形家族独立性与复现归档。第一轮未通过 B3 门槛；第二轮未完成时不能宣布原路线已有正或负的最终结论。

## 2. 核实算法与接口

- 精读 Sur-QMIX 原文，核对价值函数梯度敏感性增强、特征处理、损失与梯度路径。原论文还包含双层 GMRF 等任务表示；适配到洪水时逐项记录继承、替换与省略，不能只打开一个梯度项就声称完整复现。
- 核实作者代码归属、许可证和依赖；目前没有在本地交接材料中确认 Sur-QMIX 作者官方仓库，不能用通用 QMIX 仓库冒名。D-QMIX 只作为辅助动力学任务的参考，不能当成 Sur-QMIX。
- 先完成两机同步时钟、沿途观测、共享去重、碰撞、奖励、终止和集中训练状态接口，再接入共享 CNN/GRU、QMIX 混合器、回放及目标网络。
- 所有主比较的 Sur 开关、辅助任务开关、物理开关分别记录。训练辅助损失必须有可核查的梯度路径影响策略所用表征；完全独立训练的预测器不能被写成已改善策略表征。

## 3. 冻结信息权限与预测任务

执行输入：实际已到达的稀疏干湿标签、时间与缺失掩码、历史、位置航向、已声明的共享信息及静态地形。保持现有传感假设。

候选最小任务：从合法历史形成潜在水情状态，预测一个决策间隔后的水深及两个方向通量，并导出干湿变化。先从现有 10 秒决策间隔开展开发集可行性检查，数值约束仍须使用与求解器一致的内部积分或合适的离散积分形式；正式时间尺度由开发结果与资源测量后登记，不能视为已冻结。

连续水深和通量只作训练监督，不作为隐藏的执行输入。二值观测不能唯一确定连续状态和未知来水；需要记录无法辨识的情况，并评价干湿概率或不确定性，不能把单一连续预测当作可直接观测的真实场。若只能依赖额外水深传感才有效，应写成另一个传感假设下的结果。

训练期可使用回放中真实未来水情作为监督标签；未来雨量、来水时程与未来观测不能进入决策时刻特征。执行时的外部预报如未明确定义可用来源，一律不读取事件真实未来强迫。

## 4. 先做模型可行性诊断

用相同合法输入和采样分布，对比持续性/历史预测、纯数据辅助模型和同结构物理约束模型。开发数据应覆盖旧记录失准、涨退前缘和干湿边界，不能只看大面积稳定区域的平均误差。

物理约束候选包括离散质量、动量平衡和非负水深。先核对地形源项、雨水、入流、排水、摩阻、边界与单位；将约束算子作用于真实仿真序列，先测离散误差基底。过程导出的粗时刻不等于求解器内部时间步，不能要求粗差分残差严格为零，不能用错误残差训练模型。

这一阶段只诊断模型是否可学、权限是否正确和物理损失是否可用，不据此宣称策略有效。若不可辨识或预测不稳定，记录原因并收窄任务，不直接放大强化学习训练。

## 5. 小预算贯通四组，再冻结正式预算

| 组别 | 主要作用 |
|---|---|
| QMIX | 基础协同学习参考 |
| Sur-QMIX 适配版 | 检验继承的价值梯度增强，记录与原论文差异 |
| Sur-QMIX + 数据辅助模型 | 检验额外动态辅助学习 |
| Sur-QMIX + 同一辅助模型 + 物理约束 | 检验物理约束的额外贡献 |

后两组严格匹配辅助网络、训练标签、数据、选型机会与更新次数；物理组增加的计算开销另报。四组尽量匹配策略容量与环境步数，不能把无法同时匹配的开销藏起来。各组独立训练，保留 R0/R1/R2 竞争基线。至少三个训练种子用于描述训练随机性，不能代替独立洪水事件。

先用开发事件测得四组可运行性、内存、耗时和学习曲线，再在确认性训练前登记正式环境步数、更新预算、候选损失权重、选模规则、家族划分、种子、停止条件和任务相关门槛。当前草案不捏造尚未测得的训练预算。

## 6. 在全新事件上评价闭环任务

主指标沿用按物理时间积分的按类当前正确覆盖；同时报告变化发现、未知比例、观测错误、飞行/转向/碰撞代价，逐事件比较。预测误差、前缘识别、守恒误差、训练稳定性与开销作为辅助指标。确认性地形及来水不参与损失权重、时间跨度或检查点选择。

预测图不能刷新实际观测时间戳，不能增加真实首次覆盖；如果首轮执行时移除辅助头，则不额外把预测图输入策略。若改成执行时利用预测图，必须在纯数据与物理两组同时启用相同接口，另行登记这一变化。

物理组必须首先与同结构的数据辅助组比较，才能识别物理增量。预测更好但闭环无收益，只支持预测层结果。均值不稳定、跨事件退化或新增开销过大，均如实报告，不能靠换测试集维持正结果。
