## 基线实施时必须解决的事项

1. 构建真正同步的两机四动作环境，按共同5秒实际帧沿途采样、10秒联合决策，确定共享记录、起点、碰撞处理、奖励与截止bootstrap规则。不能把两个单机任务分别推进后当作同一个同步环境。
2. 观测编码只消费执行可用的共享/局部记忆和静态地形；全局真水情仅给训练混合器与显式辅助监督。未知、实际干燥和预测值保持不同语义。
3. 保留所有方法相同的基础网络，Sur开关只改变训练期惊奇增强；用训练与执行检查、实际参数容量、保存/加载与恢复结果证明接口一致性。
4. 先测量小预算资源，再登记正式步数、更新次数、回放大小、截断长度、检查点规则和开发集；不照搬原文1e5回合并承诺本机可以完成。
5. 后续物理辅助损失接入同一基础表征，与Sur机制分别开关。四组主比较只能支持逐项增量，不能在没有相应因子对照时声称Sur与物理约束存在交互增益。

## 当前结论

已有可复用的QMIX组件和与原文形式相符的惊奇增强骨架，材料及GPU环境足以开始适配。当前缺口是任务接口、若干未指定的实现约定，以及实际训练验证；不是从零缺少全部算法代码。尚未得到当前任务的Sur-QMIX训练结果。
