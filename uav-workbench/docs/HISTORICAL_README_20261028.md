## 启动

Python 3.10或以上，基础运行仅需NumPy。推荐单独虚拟环境；本次实际核验使用Python 3.12.14、NumPy 2.3.5。

```sh
cd uav-workbench
python -m pip install -r requirements.txt
python console_app.py
```

网页只提供现行八方向双任务工作台。B1/B3的探索—搜救检查点可做模型工程核查，其他组别可选择和导出配置；尚无模型时明确禁用执行。原四动作研究只保留为[历史记录](../docs/MODEL_CONSOLE_20261025.md)，不再作为当前工作台入口。

打开 <http://127.0.0.1:8767/>。服务只监听本机。`--port`可改变端口。Windows也可运行 `启动工作台.ps1`，它优先寻找已有可用解释器，不自动安装依赖。

仓库附带三类合成水动力开发过程和一段人工逻辑验收时序，不依赖本地生成缓存。另会自动发现原方案指定的 `maps-dca2287a0ca2` 本地导出包。支持导入洪水工作台导出的完整ZIP；网页MVP限制64×64、241帧、32MB压缩包。

选择“逻辑验收：旧记录与返回纠正”会自动填入固定动作与参数：目标格在t=1变为淹没，无人机因朝向已看不到它，认知图保留t=0干燥记录；t=3转回后纠正。**该人工时序只验证实现，不作为洪水机制证据。**

## 运行与复现

```sh
python -m unittest discover -s tests -v
node --check static/app.js
python run.py audit fixtures/rapid/map-result.zip
python run.py demo --scene logic-demo --output generated/my-fixed-demo
python run.py demo --scene rapid --method R2 --output generated/my-rapid-demo
python run.py pilot --output generated/my-pilot --durations 300 600
```

每套任务预算为三类过程×三策略×三个预先登记起点，共27次；上面的两套预算共54次。同一事件的起点、策略和预算不是新增独立事件。输出目录必须不存在，避免覆盖运行记录。

导出科学曲线需要额外安装Matplotlib：

```sh
python -m pip install -r report-requirements.txt
python run.py report generated/my-pilot --output generated/my-report
```

`build-fixtures`和`build-logic-demo`提供从源头重建入口，但会拒绝覆盖已有过程。需要重建时，请在独立的新克隆中先将对应fixture移至备份目录，再执行；不要覆盖历史输入后继续沿用原运行编号。水动力开发过程使用仓库现有 `flood_solver.py` 求解器，默认不需要Java地形生成器。

## 信息、坐标和时间契约

- 原始数组为`[field,z,x]`，字段为depth/u/v/maximum_depth，小端float32；只读取实际计算帧。最终`M_water`不充当过程真值。
- 局部米制坐标以第一格中心为原点，x向右、z向下。绝对首格中心为`origin_blocks × metres_per_block`。物理域在外圈格中心之外再延伸半格。
- 航向0°朝+x，90°朝+z；左转减角度，右转加角度。前进、原地转向、悬停共享固定决策时长，均可采样；边界采用位置截断，记录实际飞行距离。淹没不会成为空中禁飞区。
- MVP要求均匀过程帧、感知周期等于实际帧间隔，动作含整数次采样、任务含整数个动作。不提供未来帧替代或插值感知，不跳过中间实际帧的变化。
- 格中心按距离和夹角判定可见，所在格单独可见；无噪声、质量为1、即时到达。未知标签为-1，干燥0，淹没1，阈值0.05m。
- 环境持有完整真值。`PolicyView`只包含只读认知记录、有限短历史、位置和地图几何，不包含未来来水或隐藏水情。网页中的真值、失准边框只供人类回放/评价，不传给策略。
- 认知记录保留观测时间与到达时间。旧消息不能覆盖新记录；相同观测时刻保留首先接收的记录。未到达消息拒绝接收。

## 策略与评价

R0使用预先生成的蛇形航点往返，转向由共同运动模型执行。R1/R2共用两步几何前瞻、候选动作和确定性平分规则；R1按未知格收益选动作，R2再加记录年龄收益。它们均不查询水情真值或按未来变化规划。当前R0是起步扫描基线，尚未做航线效率优化。

主指标先对当前存在的淹没、未淹没类分别计算“已知且正确格数/该类总格数”，取类均值，再用实际采样时刻的左矩形积分。未知格不进入正确分子。单一真实类别仍正常评价。

变化以每格二值状态改变划分段，下一次反向变化或任务截止结束该段。必须取得变化后的实际观测才算发现。未发现项保留`detected_s=null`，受限延迟计至段结束；该统计不是只对发现成功项平均的延迟。重访间隔仅统计脱离视野后再返回的观测间隔，连续驻留采样单独登记。
