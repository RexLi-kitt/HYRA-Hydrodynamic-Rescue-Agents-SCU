用户明确要求保留双层 GMRF 和八方向移动，并确认第二层按论文保留“待救人员信号”，加入搜救目标。已在独立 `sur_rescue/` 包和 `/rescue.html` 页面实现。原四动作网络、12个选定模型、原P3及科学机器学习首轮的源码和结论保持冻结。

## 与论文对应的实现

来源：徐洲、李冠雄、邓小刚，《面向探索-救援权衡的无人机集群自主协同搜救方法》，第2.1、2.2节及式(6)–(31)。本地原文与提取文件沿用 `SUR_QMIX_IMPLEMENTATION_AUDIT_20261025.md` 中的路径。

| 论文机制 | 本次实现 |
|---|---|
| 环境结构 GMRF | 高斯SAR `(I-C)(X-mu)=epsilon`，观测后更新均值并切断已探索格的关联边 |
| 人员信号 GMRF | 在非障碍格建立SAR相关场，目标邻域提高相关权重，乘以到最近人员的高斯距离衰减；已救人员仍保留信号源 |
| SAR可解性 | 非负C的最大行和不超过0.35，谱半径小于1；删边只减小既有系数，固定点迭代报告残差与误差界 |
| 九通道观测 | 4通道局部图 + 4通道池化全局图 + 1通道池化位置图，均为5×5 |
| 八方向动作 | 左、右、上、下、左上、左下、右上、右下；每5秒移动一个相邻格，无转向或悬停动作 |
| 联合运动 | 处理越界、障碍、对角穿角、相向交换及对角路径交叉；运动受阻与施救停留分别记录 |
| 搜救交互 | 发现目标后可接近；到达格点自动开始施救，停留10秒后完成 |
| 网络 | 共享CNN、观测/上一动作/时间嵌入、GRU、8维Q输出，以及集中训练QMIX混合器 |
| 惊奇增强 | 最大Q关于观测嵌入的梯度L2范数，按有效批次智能体归一化并沿固定单位方向注入；执行关闭 |
| 奖励组成 | 新增探索收益、无效动作惩罚、距离加权施救收益、团队延迟惩罚、截止剩余人员惩罚 |

八方向采用论文式高层网格动作：直向距离为一格，对角距离为√2格，相同决策时间下对角物理速度更高。本实现没有宣称对角动作满足原四动作环境的恒定地速约束。

## 保留的适配约定与局限

- 人员和不可通行格是显式合成的场景叠加，不是从洪水图中识别到的人或障碍，也不把淹水格直接当作无人机飞行障碍。原始水力计算不改写。
- 物理信号场在环境内部生成；策略只读取传感窗口实际采集并共享的信号值。未发现人员坐标和未观测障碍不进入actor；真实水情仅用于传感、集中训练状态和离线评价。
- 沿用可靠共享观测，这与论文强调无显式通信的执行方式存在差异。全局隐藏真值不会进入执行actor。
- 尚未用水深约束人员生存或施救可行性，不能把当前叠加模式当作完整洪水救援物理模型。
- SAR相关强度、噪声、距离尺度、删边细节、网络宽度、惊奇度min-max/停止梯度、目标分支关闭增强、目标同步周期、延迟惩罚下限和施救除零保护均为明确实现约定，未确认与作者代码完全相同。
- 训练为12回合工程试验，批量4、buffer32、RMSprop 1e-4、gamma0.99、每5次优化同步目标网络；不等于论文10万回合及原环境训练预算。边界/已知障碍可用动作掩码也单独登记。

因此当前状态为“已接入论文双层GMRF与八邻域机制的搜救适配实现”，不宣称原论文结果复现成功。

## 实测与验证

七项测试通过：SAR与独立稠密线性方程解一致及高斯精度矩阵正定；删边后系数不增加；256×256稀疏模板计算；人员信号衰减和障碍置零；八个相邻方向位移；边界/穿角/交换/交叉碰撞；九通道只读观测和传感权限；施救停留与截止；新网络梯度、参数更新、四动作输入拒绝及执行禁用集中真值。

QMIX8和Sur-QMIX8各实际训练12回合，每组9次优化；均以独立进程完成前6回合，再从检查点恢复至12回合。新actor输入为9×5×5、输出8维，从头初始化，未转换旧四动作权重。计划、每回合恢复文件、初始/最终权重、训练历史和摘要存储在 `generated/sur-rescue-pilot/{QMIX8,Sur-QMIX8}-s11/`。

端到端证据见 `generated/rescue-validation-20261026.json`。四次回放的独立核查重建了传感窗口、实际水情、观测地图、人员信号记录、八向位移、航程、交叉碰撞、目标发现/施救停留和GMRF残差；全部通过，原35份科学源码摘要一致。
