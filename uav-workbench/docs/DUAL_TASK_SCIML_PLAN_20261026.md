# HyRA：双层GMRF、Sur-QMIX与科学机器学习双任务执行方案

日期：2026年10月26日。状态：研究范围已确认，实施与正式实验登记分阶段推进；不是已完成的性能实验报告。

## 1. 已确认的研究主线

用户明确要求同时使用两项已有方法：双层GMRF环境建模、基于价值梯度敏感性惊奇增强的Sur-QMIX；保留八方向移动；分别开展自主探索和探索—救援两类实验；进一步加入科学机器学习，检验水动力物理知识是否提高协同任务表现。

总体链路为：洪水工作台实际水动力过程 → 合法局部观测与双层GMRF结构表征 → 共享编码与时序记忆 → Sur-QMIX八方向协同决策 → 探索或探索—救援评价。训练期增加物理约束辅助学习，执行期仍以实际观测维护认知地图。

双层GMRF和Sur-QMIX是引用与复用的已有方法。新增候选贡献是“水动力物理知识如何进入共同表征并改善两类任务”，必须由受控实验支持，不能把已有方法改名后当作原创贡献。用户提供的贡献段落作为需求来源，不能将其正向结果直接写成HyRA已经获得的结果。

## 3. 两类实验必须分别完成

### E1：自主探索

基础任务为无人机在未知障碍环境中探索和覆盖区域，不启用施救，不发放救援奖励，不因不存在人员而触发救援超时惩罚。真正无人员的探索条件中，人员信号场按无源条件为零，保留相同结构接口；不能凭空添加可利用的隐藏目标。另设“有线索但不施救”时，必须单列为目标搜索条件。

先核查与论文任务对应的小尺度设置，再在洪水工作台生成的动态过程上检验探索—复查选择。基础探索报告首次覆盖曲线/AUC、达到预定覆盖率的时间、重复访问、路径长度、无效动作和冲突；洪水扩展层另外预登记时间积分的当前水情正确覆盖、陈旧记录错误与变化发现延迟。两层任务的指标分开报告，不把首次覆盖率冒称当前水情正确率。

### E2：探索—救援

保留未知人员、弱信号感知、发现—接近—施救流程、施救占用时间和八方向动作。将动态水情接入可服务窗口或服务完成条件，使“先探索还是先施救、何时到达”确有代价差异。具体阈值属于合成任务配置，事前登记并做敏感性检查，不解释为真实人员存活模型；也不将地面淹水自动判作无人机禁飞。

主指标为截止时成功施救比例；同时报告首次发现/首次施救时间、全部施救完成时间、任务失败类型、探索覆盖、航程与冲突。未完成的任务保留截止和删失标记，不能只对成功回合计算完成时间。

基础层保持论文搜救设定与差异台账；洪水扩展层清楚区分“静态叠加目标”和“水情会改变可服务性的动态任务”。只在后者评价水动力知识的任务价值。

## 4. 同时保留的核心方法

1. 双层GMRF分别表达环境结构和待救人员信号。SAR非负相关矩阵保持谱半径小于1；未知信号的估计与实际传感记录分别存储，估计不能修改实际观测标签或时间戳。
2. 八方向采用显式动作表，处理越界、障碍、穿角、交换和交叉冲突。原论文式一格动作与米制速度约定分别记录，所有比较组共享相同运动时间和成本。
3. Sur-QMIX保留CNN、上一动作与时间嵌入、GRU、QMIX混合器，以及价值梯度惊奇增强。增强仅用于训练，具体归一化、方向、停止梯度、目标分支和目标更新规则逐项登记。
4. 九通道结构观测继续保留。洪水扩展层另接合法水情观测分支，包含已采集水深/可用流速、位置、有效掩码及真实观测时间；静态底床和其他先验列入统一权限表。不能只给Physics组额外水情输入。
5. 论文一致性校验使用论文规定的机数和任务尺度；当前2机工程版本需要补齐可配置机数。实际洪水扩展的机数、传感范围和通信方式另行固定，不把可靠共享观测版本冒称论文的无显式通信执行版本。

## 5. 科学机器学习的第一条可检验路线

本轮先做“物理约束辅助表征学习”。辅助模型读取与策略共享的合法历史编码、循环状态和允许静态地形，预测短期守恒状态；学习梯度必须实际回到策略编码器和GRU。训练期真实当前/未来水情可作为监督标签，不能作为actor隐藏输入。

候选状态为 `U=(h,hu,hv)`。总损失分为TD任务损失、共同数据监督，以及物理组额外的浅水方程离散一致性。守恒、源项、边界和非负条件在所支持数值子集中处理；先验证算子，再在开发集决定尺度归一化及权重，确认评价前冻结。

优先复用已验证的离散浅水方程算子，适配新八动作网络与实际数据。物理短步必须对应求解器接受的内部步长，不把5秒导出差分当作任意内部离散方程。局部残差和空间求和体积残差分别统计，避免正负抵消被误判为处处守恒。

第一轮不同时引入模型内规划、虚拟强化学习回放、改变奖励和流向GMRF相关系数等多个新机制。若后续让预测显式参与选动作，应另设Data与Physics共同预测接口，单独登记新实验。当前辅助学习不是已经实现的世界模型规划器。

该路线是HyRA待检验的研究设计；物理约束参与神经网络训练的一般思想可参考[PINNs作者项目说明](https://maziarraissi.github.io/PINNs/)，不能由该参考推断它一定提高本项目的强化学习收益。

## 6. 每个任务共同执行的最小比较矩阵

| ID | 空间表征 | 协同学习 | 辅助监督 | 用途 |
|---|---|---|---|---|
| B0 | 同源原始观测编码 | QMIX | 无 | 基础对照 |
| B1 | 双层GMRF空间编码 | QMIX | 无 | GMRF收益 |
| B2 | 同源原始观测编码 | Sur-QMIX | 无 | Sur单独收益 |
| B3 | 双层GMRF空间编码 | Sur-QMIX | 无 | 联合基础方法 |
| D | 同B3 | Sur-QMIX | 数据监督 | 区分额外监督的作用 |
| P | 同B3 | Sur-QMIX | 与D相同的数据监督，加物理约束 | 检验物理约束的增量 |

B0–B3是表征×惊奇增强的2×2对照。所有组使用同一场景、传感信号与可用历史；关闭GMRF编码时以同源原始观测替代，维数和网络容量尽可能匹配。不能通过不给基线人员信号或水情输入制造“表征收益”。真实物理信号生成过程在各组间保持一致；如对比论文的0-1信息版本，必须单列说明信息量差异。

D与P的结构、数据、标签、初始化种子、优化步和选模机会相同，差异限于登记的物理损失。P相对D是物理约束的主要增量比较；P相对B3反映完整附加机制收益，但不能单独归因于物理知识。本矩阵不支持宣称任意Sur×Physics交互效应。

另加入统一八向动作和感知条件下的扫描、前沿探索，以及适用于E2的信号/任务时限规则基线。比较对象必须有实际合理行为，不能只以弱学习基线宣布提升。

两个任务×6个学习组×3个训练种子（11、29、47）=36个拟正式训练任务；这是执行矩阵，不是36个独立场景。完整训练预算尚待开发集学习曲线与资源试跑后统一冻结；本方案没有启动这36项正式训练。

## 7. 数据、尺度与统计

- 按母地形、障碍结构、来水模板和人员场配置记录依赖关系；拟合、选型、确认集在适当的独立场景单位上隔离。训练种子、同一地形的来水变体、机位、帧和像素不计作额外独立地形。
- 两任务和各方法使用配对的场景与种子设置。报告逐事件结果及按独立场景聚合的不确定性，保留失败、超时与NA。
- 用真实洪水工作台过程做动态评价。先补齐任务时长内的实际帧，再决定训练/评价预算；当前256×256的10秒包不满足完整任务条件。
- 小尺度用于机制与学习调试，大图用于原格距迁移和长时任务验证。学习模型的大图验证与规则接口能读大图分开验收。
- 传感与动作周期、求解器内部步长、预测时距分别记录。静态水情、缓变、快变作为机制边界对照，不预设物理组必须在所有条件下获胜。
- 先在开发集评估是否存在合理的探索、复查与施救取舍，避免预算不足到各组均无机会完成任务，或强规则已满分造成无法判别。

## 8. 实施顺序和阶段产物

| 阶段 | 必须完成的工作 | 产物与进入条件 |
|---|---|---|
| A 方法一致性与双任务接口 | 论文差异台账、E1无人员模式、E2发现/施救、可配置机数、相同八向动作 | 两任务确定性轨迹、奖励与终止审计；不是新12回合模型即代表性能复现 |

| C 强基线与学习预算 | 规则对照、B0–B3开发集训练诊断、资源/保存恢复/选择规则 | 共同预算与配置事前冻结；平台期或固定回合数不能单独证明收敛 |
| D 科学机器学习接入 | 共享梯度、共同Data分支、SWE算子与标签验证、D/P开发检查 | 同一输入、结构和标签的对照成立；冻结物理权重与数值子集 |

| F 原始大图与交付 | 长时原网格任务、分块回放、迁移失效分析、可复现归档 | 区分接口成功、任务可执行、任务收益以及真实事件适用性 |

现阶段从A、B开始，不能直接把旧四动作辅助头接到新八动作网络后宣布整轮完成。新实现应在独立版本中推进，保留当前工程检查点和旧研究。洪水端与无人机端继续使用既有分离目录，不重新混放两个工作台。

## 9. 验收与结论边界

本轮最终交付包括两任务环境和权限说明、原论文机制差异表、训练/恢复与模型选择记录、统一基线、逐任务和逐场景结果、消融比较、物理算子审计、大图测试和可重放日志。

只有P相对D/B3在预登记的任务指标上获得可靠增益，并且约束成本或失败率可接受时，才支持“科学机器学习优化了该任务”的结论。预测误差或方程残差下降本身不够。改善某一任务不能自动外推到另一任务；静态或小图结果不能自动外推到动态大图或真实救援。

若P未改善任务，保留结论并检查信息相关性、学习稳定性、辅助梯度干扰和任务可行动性，不追加确认集调参直至获胜。
