# 旧模型联动与256—1024—2048训练补充协议

日期：2026-11-01。用户已授权在准备检查通过后开始训练。本补充为新的研究实验，保留上一版8页计划书与208次预选的全部失败；不追溯修改原预选门槛或将新实验说成旧门槛已通过。

## 目标与候选

在同一四机搜救任务中共同控制、共同采样、分别更新两种模型，检验旧模型能否通过协作训练提高完整任务完成、人员服务和覆盖，同时控制潜在冲突。不是将两个独立分数平均，也不是本轮实现新的高层任务头。

|组合|模型初始化|依据|
|---|---|---|
|HATRPO＋HASAC|HATRPO既有512较优检查点；HASAC既有256较优检查点|结合信赖域策略更新和离策略学习；保留此前组合退化作为对照|
|HATRPO＋MAAC|HATRPO512；MAAC256|检验注意力评论器是否改善协同，MAAC在固定执行补漏对照中冲突较少|
|HASAC＋MAAC|HASAC256；MAAC256|比较两种离策略学习器的共同任务表现|

不使用MAPPO、QMIX、VDN、IPPO、DQN、DDPG；不恢复已经退化且无新机制支持的MAT/COMA长训。

## 训练和控制保持一致

- 每组两种模型各负责两架无人机，使用对角分工；每16回合交换分工，16个训练父水场都经历两种分工。
- 旧权重作为初始化，新增4个公开分工标记的输入权重为零。新优化器和经验缓存从空开始，不把该操作称为原训练状态无缝续训。
- 自动施救、受阻重试和连续5步无新增覆盖后补漏均在训练与评价中启用。规划先于网络采样，用公开位置和已观测记忆决定受控动作；强制动作采用单选掩码，不作为自由策略动作计入学习贡献。
- 两回合中模型保持不变，完成后先更新HATRPO自己的动作，再更新HASAC/MAAC自己的动作。评论器使用共同观测、实际动作和混合队友生成的下一步动作；未控制的角色不更新该模型对应的策略网络。
- 沿用原奖励、300步、每步5秒、1km区域及20人、服务10m/10秒和原水情阈值。发现、服务和任务完成分列；没有发现的目标不删，不可完成的目标不从分母移除。

## 数据与评价

训练父水场由4扩为16，验证父水场由2扩为6；新增父场在查看模型结果前固定种子。全部为同一生成机制的合成浅水场，保留有限非负、源体积与水量检查。既有现场洪水定性验收与本训练分开。封存50场测试不使用。

每次联合模型评价为6父水场×2布局×2分工×（2种随机动作种子＋1种固定动作）＝72回放。旧/新父场、随机/固定、两分工分别保留；不能把72回放当72个独立洪水事件。本次是一训练种子1001的筛选，不能代替三训练种子的稳定性确认。

每组在第0回合按新控制器重新评价，作为训练收益基线；0、256、1024和实际执行的2048终点还做关闭补漏的独立对照，保留其完整失败。本轮计划不是改变评判尺度以制造训练收益。

## 分阶段预算和选模

1. 三组各新增256个共同任务回合；每64回合保存完整可续训状态并评价。
2. 按各组最佳已存检查点选择前两组，继续其最新训练状态到本轮累计1024；每64回合保存，每128回合评价。最佳版本与最新版本分别保存，终点不自动取代最佳。
3. 排名事先固定：先少违反分层平均潜在冲突/步≤0.02的组数，再依次比较完整任务比例、人员服务比例、较差分工服务比例、覆盖、较少冲突和较少截断步数。同分按组合名称固定排序。入选1024仅为相对较优的研究探索，不等于通过验收；原纯规划对照保留。
4. 2048仅对至多两组入围者开放：768→896、896→1024连续两个区间都有明确收益；完整任务与人员服务不下降，覆盖最多下降0.001，每个旧/新×随机/固定分层冲突≤0.02，单回放潜在冲突最多10；且1024相对256有明确收益，最佳版本出现在256之后。
5. 明确收益为任务比例至少增加1/n，或服务增加0.005，或覆盖增加0.005，或在上述任务指标不降低的前提下平均截断步数减少至少5。停止扩训不删除后期退化。

总上限4352个新增共同任务回合：3×256＋2×768＋2×1024。一个共同回合不因含两种模型而计算两遍。现有各父模型历史训练量另外登记。训练仍为单CPU两线程串行，不同时运行洪水重负载，不用子代理。

算术更正：最初冻结的protocol.json说明文字将上述和误写为4864；实际代码的三阶段回合目标从未改变，上限应为4352。原协议保留，本更正不调整候选、分类、数据或晋级门槛。

## 完整性与停止

启动前核验父策略补维等价、两成员参数实际更新、角色外策略参数不变、检查点含优化器/缓存/随机状态并可精确恢复、强制动作掩码与因果输入。每阶段保留逐回合日志、72次完整对照、动作和位置轨迹、目标末态、全部检查点及哈希。

人工STOP_AFTER_CHECKPOINT在完成当前两回合更新块并保存后停止；数值、运行或哈希失败即停止并保留失败，不自动重试。阶段边界空闲磁盘低于8GiB或累计超过4小时不再启动下一阶段。估算时长在实际首段测得速度后更新，256—1024—2048均指共同任务训练回合而不是秒数。

原代码、模型、输入和历史分数不覆盖。本轮隔离目录可整体停用并返回原入口。记录与研究报告同步到outputs和项目docs；大型水场和完整检查点在live-run指向目录保存、索引含来源与哈希。不会自动推送PR、外发或安装软件。

## 依据和限制

[HARL论文](https://www.jmlr.org/papers/v25/23-0488.html)用于异构顺序学习依据；[MAAC论文](https://proceedings.mlr.press/v97/iqbal19a.html)用于注意力评论器依据。混合训练及规则掩码属于项目适配，不继承论文的单调改进保证。

尚未实现新的高层任务分配接口，尚无三训练种子复核；建筑、天气、通信、续航与真实施救能力未在本实验中验证。需要后续独立阶段，不能将本轮比例当现实搜救准确率。
