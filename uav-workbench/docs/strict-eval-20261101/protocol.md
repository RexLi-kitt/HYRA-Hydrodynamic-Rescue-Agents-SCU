# 无人机单/双模型严格检验预登记 v1

2026-11-01，用户要求排查背图或作弊并采用更严格检验。本文在新测试场景生成及结果读取前登记。保留当前训练协议，不将新测试场景用于训练、挑检查点或晋级2048。

现有结果是开发验证：16训练/6验证父水场、一个训练种子，验证仅4套人员布局被多次使用，且共享覆盖规划与服务控制。理想100米扇形感知、即时共享、无建筑/续航限制使任务较易。高完成比例不能归因于神经算法，也未排除选模对验证集的过拟合。HAPPO+HASAC1024在当前72回放中完整任务71/72，关闭覆盖规划0/72，后者人员服务均值0.83819444、覆盖0.86730833；这是控制器贡献线索，不是已证明作弊。

1. **先检查权限。** 对六算法和两种双模型分工，改变未发现目标、未观测当前水情、未来水情，固定已有观测历史与随机状态，检查观察、合法动作掩码、策略动作和规则控制输出相同。检查权重不变。环境可以用真实水情判定过去一个已执行区间的施救结果；这不等于把未来给策略。源码检查与动态检查分别留档；通过只排除已测试泄漏路径，不能证明绝无缺陷。
2. **锁定待测对象后才生成场景。** 等6个单模型完成1024及已登记的条件2048、旧15组合结束并通过审计；用各自既有验证best.json锁定21个检查点并保存SHA256。锁定后由系统随机源产生测试主种子和70个互异水场种子、互异人员种子；与训练验证种子隔离。先保存种子计划和哈希，再生成文件，不看结果换种子。
3. **主测试50场。** 50个独立生成的完整地形/动态水情父场，各一份新人员布局，使用现有相同物理生成族。所有方法共享场景。单模型每场一次，双模型两种分工均测并先在场内平均。确定性动作作为主表；不得只报较好分工。相同生成族的未见样本不称任意洪水泛化。
4. **方向与布局变化20场另表。** 额外20个独立父水场，按事前固定次序旋转90/180/270度，速度矢量同步变换；人员按2个簇的固定生成规则抽样。它是方向/布局变化压力测试，不冒充全新水动力生成族或现场洪水。未改感知半径、时间、目标数及成功门槛，不会让硬编码100米的规划器错误猜测覆盖。
5. **所有21种方法均有配对消融。** 同场比较完整方法和关闭覆盖规划（保留相同服务/重试控制）；另加入纯观测信息覆盖规划+服务基线、均匀随机探索+相同服务/重试基线。每条记录报告规则接管、自由决策占比、人员服务、完整任务、覆盖、潜在冲突、ST、FRT、CRT及超时；关闭覆盖的结果不称纯神经网络，服务规则仍存在。不能用训练奖励当成功率。
6. **随机性补充。** 测试前从既有验证排名确定1个单模型、1个双模型，仅这两种另做3个固定动作采样种子、全部50主场景的稳定性补充。完整21方法确定性主表不删。不把动作采样重复当独立训练种子。仍只有一个独立训练种子，跨训练种子的可靠性未验证；若后续重训须另开开发集及下一次最终测试版本。
7. **统计与防挑结果。** 先按场景等权，再按父场景聚类自举10000次给95%区间；双模型两分工不可当两个独立地图。对预先锁定的单/双代表相对纯规划的配对差值，提供97.5%区间以覆盖两项主要比较；其他21方法差值为描述性，不声称经过多重比较证明谁最好。另对“每个父场的全部分工/重复均完成”给Wilson95%区间，即使50场全成功也不能用退化自举区间声称真实100%。显示全部失败场、较差分工、低尾部和原始分子分母。测试不自动改best.json、扩训名单或奖励。
8. **物理与指标审计。** 新水场必须有限、深度非负、闭域源体积与存量相符；无效场景停止调查，不按救援结果替换。隐藏、发现、抵达、开始服务、完成服务分开；20人分母不因不能服务而缩小。任务完成严格为全部网格实际观察且20人完成服务；完整轨迹核对服务事件、末态与原始冲突。保留不可救窗口诊断，不反向帮助算法。
