# V44 搜索分叉与送达差学习

固定原场景规则。在任务第 180、510、840 秒起各一分钟内，对第一个有不同首动作候选的自由机搜索决策，保留原选项或采用原候选中分数最高的不同首动作航线。无人机只使用已观测水情、队友位置、走过区域与原候选分数。追踪与投放仍有优先权。每个窗口最多干预一次。

训练采用 V10/V11 压力父图各索引 0–3，双水情，名单 0。在原轨迹上分别干预一个窗口，其余行为延续原 V44，跑至 2400 秒。把该场最终全队送达人数与原版相减作为标签。同一时刻对照起始决策必须一致。缺少可选决策的窗口登记跳过。用八项固定特征作岭回归，截距不惩罚，其他系数惩罚 4，不按测试结果选阈值。预测净增大于零才换路。

评估用上述两个来源各索引 4–7 的另外 8 张父图、双水情共 16 场。按全体 1024 人次计算送达，另列逐人发现及送达。对照当前连续搜索 V44、同场既有强纯规划，以及总是换路的消融。测试每场可连续使用三个窗口。只有同时超过三种对照、两类水情均优于当前 V44、相对当前 V44 的基础图配对 95% 重抽区间下界大于零，才复核历史 80 场混合面板。开发筛查失败保留试验入口和权重，默认仍采用原策略。正式封存图不参与。
