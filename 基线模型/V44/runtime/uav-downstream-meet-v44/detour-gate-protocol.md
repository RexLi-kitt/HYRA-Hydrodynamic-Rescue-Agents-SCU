# V44 边缘改道与原航线的机会比较

固定 64 人、12 分钟个人窗口、40 分钟任务与碰边停留。只改压力搜索分支。每次原搜索计划与考虑边缘收益的计划不同，比较即将实际执行的动作前缀。按两条路线各自的 20 米前向半圆，分别估计沿途可接近的内区人群、真实边线位置上可接近且仍有投放时间的未见人群。已扫区域在同一条路线内去重。仅当边缘增益为正且足以补偿内区损失才改道。该估计是排序分数，不是已校准的实际送达概率。不训练、不调阈值。

先复用原 A/B 各 20 张混合开发地图（A 名单 0，B 名单 1），比较原 V44、上一版边缘搜索与强纯规划。另在此前没有用于这项改动的 V50 八张压力父图、每张双水情名单 0 上，以碰边停留规则重跑各法。三个集合均保留。仅当两个混合组与单独压力组的新策略总数都高于原 V44、混合合计高于上一版边缘搜索及纯规划时才推荐替换；否则按实际结果保留候选。分别报告边缘送达与其余送达，分母含所有人员。复用图均属开发数据。
